# 事件怪物殖民地攻擊規格

## 目標

依 `docs/re/event-monster-colony-battle-audit-20260825.md`，讓事件怪物抵達受害殖民星後自動進入
防禦戰與三輪戰略轟炸，不再只建立靜態 `MonsterGuard` 等玩家主動處理。

## 流程

1. `TransitETA` 由 1 變 0 時先標記抵達；太空鰻到此停止，不攻擊殖民地。
2. 其他事件怪物找出目的星目前仍存在的玩家、熱座或 AI 殖民地；沒有殖民地時保留停泊怪物，
   不憑空製造傷害。
3. 殖民地固定防禦先對怪物開火。怪物結構歸零即移除，不進轟炸。
4. 存活怪物固定執行三輪轟炸；每一輪每個同星同種類個體依目前可表示怪物武器資料產生一次
   傷害，逐發套行星護盾，再將三輪總傷害 `/40` 向下取整成戰略 hits。
5. hits 送入 `ResolveStrategicColonyDamage`，沿用已證實的建築／陸戰隊／戰車／建造進度／人口
   候選池。回寫所有平行陣列及建築效果；殖民地毀滅時移除殖民地並重算星系 owner。
6. 產生玩家可見抵達／防禦成功／傷亡／殖民地毀滅訊息；同回合只消費一次。

## 證據邊界

- 三輪、`/40`、太空鰻排除、共同殖民地傷亡 consumer 與殖民地移除是已證實。
- 怪物精確 blueprint 尚未閉合；火力、結構及固定防禦戰採現有手冊資料與 remake combatant，
  必須標為 blueprint approximation，不能用綠測試宣稱原版精確數值。
- 熱座非目前席位必須透過席位快照切換後寫回，不可只傷害目前載入玩家。

## 驗收

1. 太空鰻抵達殖民星不造成傷害。
2. 其他四種事件怪物抵達時自動結算；沒有殖民地時不傷害任何帝國。
3. 三輪總傷害與 `/40` 邊界測試；行星護盾逐發減傷。
4. 固定防禦可在轟炸前擊殺怪物；無防禦時怪物保留並轟炸。
5. 玩家、非目前熱座席位與 AI 各有傷亡／殖民地移除測試。
6. JSON／多人快照、正常 `EndTurn`、全專案回歸及 Docker 清理通過。
