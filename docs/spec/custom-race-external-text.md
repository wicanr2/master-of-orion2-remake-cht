# 自訂種族外部文案與安全框規格

## 資料與識別

1. `pickCat.id` 是規則層識別；戰鬥、諜報與政府分支只能比較 ID，不可比較翻譯文字。
2. `pickCat.textKey`、`pickOpt.textKey`、`specialPick.textKey` 只保存 `customrace.*` 語意鍵。
3. 玩家可見中英文位於 `assets/i18n/ui.json`；原版標籤採
   `docs/re/custom-race-ui-text-audit-20260826.md` 的 RACESTUF asset 0 順序。
4. 數值類未選狀態的 `textKey` 為空，畫面顯示空白；不得自行補 `None`。
5. 動態點數以程式格式化，但「剩餘點數」模板本身由 JSON 提供，兩種語言都保留兩個 `%d`。

## 文字安全框

- 標題：`20,28,600×36`；剩餘點數：`140,59,360×22`。
- 左欄每列外框由 `catRect` 決定；類別文字從 `x+8` 起、寬 `w-134`，選項從 `x+140`
  起、寬 `w-148`，兩者皆高 16。
- 右欄能力文字從 `x+8` 起、寬 `w-50`；成本使用右側 34 px 獨立框，禁止互相覆蓋。
- 底部按鈕以熱區同中心的安全框繪製，四周至少保留 5 px 水平與 2 px 垂直內縮。
- 所有欄位使用 `textSafeRect` 的單行量測與省略，不能只依 painter clipping。

## 驗收

1. 10 個類別、每個數值類 4 個狀態、4 政體及 22 能力的資料形狀不變。
2. 選項切換、互斥、點數、`customRaceValues` 與政府索引不因文案改變。
3. 中英文最長標籤經實際 runtime font 量測／截斷後不得超出各自安全框。
4. 靜態掃描拒絕 `customrace.go` 新增 `tr(...)` 或代表性中英文玩家文案。
5. GUI 抽樣需涵蓋繁中與英文自訂種族畫面；幾何測試不等於逐像素原版 parity。
