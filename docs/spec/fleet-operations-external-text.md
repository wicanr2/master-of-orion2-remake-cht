# 艦隊作戰名冊外部文案規格

## 資料契約

- 固定標頭、航行後綴、拆分提示、損傷模板、未知地點及轉場名稱只能以 `ui.json` 穩定鍵讀取。
- Go 只保存 typed 狀態、格式參數與安全 fallback；不得保存中英文玩家文案。
- 已選／未選標記沿用 `fleet.selection.*`，兩種語言必須等寬。

## 版面契約

- 標頭與拆分提示限於左側名冊寬度，過長以省略號截斷。
- 艦艇列固定分為名稱、艦級、損傷三個互不重疊安全框；每格獨立截斷。
- 安全文字框不得越入右側艦艇圖、安塔蘭入口或下方調動控制。
- 本切片不新增捲動、分頁或改變既有點擊語意。

## 驗證

- 雙語 catalog 鍵必須可解析。
- 極長艦名、艦級、星名、三位數 ETA 與損傷模板必須通過字墨界線測試。
- `fleet()` source slice 不得出現 `.tr(`。
