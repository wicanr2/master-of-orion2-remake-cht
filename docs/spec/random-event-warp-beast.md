# 隨機事件 26「超空間獸」規格

證據來源：[`../re/random-event-warp-beast-audit-20260825.md`](../re/random-event-warp-beast-audit-20260825.md)。

## 建立與 record

- 一般壞事件排程先選第一個受害帝國。
- 建立全銀河唯一 `PersistentWarpBeast`，保存 `TargetKind`、`TargetIndex` 與 `Turns=-1`；舊存檔
  缺目標欄位時零值安全回退目前玩家。
- 玩家、非目前熱座席位與 AI 都能成為當回合目標；事件本身不因換熱座席位而複製。

## 每回合攻擊

1. 先依生命週期判定事件是否解除；已解除的回合不攻擊。
2. 在 record 指定帝國所有 `ETA>0` 艦隊的全部艦艇間均勻抽一艘。沒有航行艦時不造成損失。
3. 有候選時移除恰好一艘，不得固定挑目前艦隊、最弱艦或最後一艘；軍官／衍生艦隊資料沿用
   remake 的既有安全刪艦路徑。
4. 無論本回合是否有候選船，都依事件 26 的原版受害者權重抽下一個存續帝國，保存為下回合目標。
   這一步不重新觸發 Lucky 壞事件取消，因為事件已經 active。

## 解除

- active age 0..4 不擲骰。
- age 5..20 每回合擲 `Random(20)`，只有 1 結束。
- age 21 強制結束；解除回合不刪艦、不重抽目標。
- `advancePersistentEvents` 先增加 `Turns`，所以建立值 `-1` 對齊原版首個 consumer age 0。

## 驗收

1. age 4／5／20／21 與不提前消耗亂數的邊界測試。
2. 玩家多艦隊只從航行艦抽選，停泊艦不受影響，且不依戰力挑最弱艦。
3. AI 與非目前熱座席位各能損失航行艦；目前席位與選中艦隊不被誤改。
4. 無航行艦仍會保存下一回合帝國目標；事件及目標可 JSON 往返。
5. 全專案測試、格式、擁有權與 Docker 清理通過。
