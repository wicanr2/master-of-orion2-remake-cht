# 飛彈彈架容量規格

1. 標準飛彈可選 Ammo `2/5/10/15/20`，預設 5；魚雷固定 2，其他武器使用原版表預設且 UI 不顯示彈架選項。
2. 標準飛彈的單武器 base 成本／佔格依 Ammo 分別為 `10/20/30/35/40`，之後依序套改造、微型化與火線角。
3. `Ship.WeaponAmmo` 持久化設計值；零值代表舊 JSON，讀取時依武器回退到原版預設，不批次改寫存檔。
4. `CombatShip.WeaponAmmo` 是戰鬥暫存量；飛彈或魚雷每次真正開火才扣 1。射程、射界、停滯或無目標擋下時不得扣除。
5. 彈藥為 0 時不能開火、不能解除匿蹤、不能消耗 RNG；UI 顯示「彈藥耗盡」。快速結算只有一個抽象齊射，仍以至少一發彈藥作開火閘門。
6. `CmdBuildShip.Args[4]` 保存 Ammo；舊命令缺值或為 0 時依武器預設，維持重播相容。
