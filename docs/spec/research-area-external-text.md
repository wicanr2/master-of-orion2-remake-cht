# 研究領域動態文案與安全框規格

## 文案與資料契約

- 一般主題、超進階等級、全領域完成及星系轉場模板由 `research.area.*` JSON 鍵提供。
- 主題名稱仍查 `tech.json`；程式只傳已翻譯主題名、等級與 RP 數值。
- 中英文格式參數數量與順序必須一致；`RP` 保留原版單位縮寫。
- `research()` 來源切片不得使用 `.tr(` 或直接保存上述固定句子。

## 幾何契約

- 每個動態主題框由對應 `hitRegion` 推導：x=`hit.x+6`、y=`hit.y+26`、
  w=`hit.w-12`、h=`28`。
- 12px 單行文字置中於該框；寬度超限依實際字型加省略號，高度不足時不得繪製。
- 文字框必須完整落在熱區內，且不侵入上方 18px 烘字標題帶或相鄰領域。

## 驗收

- 四個語意鍵雙語齊全，格式契約分別為 2、3、0、0 個參數。
- 八個框的最長繁中、英文與超進階等級測試均通過雙軸 containment。
- 點擊仍寫同一個 field/application，不因文案切片改變研究規則。
- `cmd/moo2`、`internal/shell` 全套測試通過，繁中／英文研究畫面實圖抽樣無越框。
