# 星圖選星側欄外部文案與安全框規格

## 文案

- 固定鍵使用 `galaxy.star_panel.*`；稅率使用 `galaxy.status.tax`。
- 環境、陸戰隊、艦員、ETA、按鈕、成功／失敗提示、怪獸／特殊物產前綴全部從
  `assets/i18n/ui.json` 取得。
- 行星名、怪獸名、環境 typed 顯示名與數值是動態參數，不得拼接固定中文標點。
- shell 的 typed／動態拒絕原因外置屬下一個規則結果切片；不得因此把本輪稱為所有星圖訊息完成。

## 幾何

- 面板固定 x=`28`、y=`326`、w=`210`、h=`140`，底緣 y=`466`，完整包含最下方
  y=`446..466` 的心靈控制列。
- 所有單行仍使用既有 `textSafeRect`；按鈕文字框與 hit rect 共用 x/y/w/h。
- 環境兩列、陸戰隊列與按鈕列不可互相重疊；超長動態名稱採單行截斷。

## 驗證

- 雙語 catalog 與格式參數數量測試。
- 幾何測試釘住所有文字框在面板／640×480 畫布內，尤其 y=446 最下列。
- 靜態測試禁止星圖側欄標記區重新出現 `.tr(` 或既有固定玩家句子。
