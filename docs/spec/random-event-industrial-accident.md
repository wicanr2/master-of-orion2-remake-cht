# 隨機事件 10：工業事故規格

依據：`docs/re/random-event-industrial-accident-audit-20260825.md`。

## 垂直鏈

1. 事件分派不得選擇具有 `TRAIT_TOLERANT` 的玩家、熱座席位或 AI。
2. 合格殖民地氣候必須高於 Radiated；抽選最多重試 200 次，失敗時選最高索引
   合格殖民地。
3. 特殊命中數為 `population*(roll3a+roll3b)/10`。每次特殊命中：
   - 先抽一名非 Android 殖民者；沒有候選就浪費本次命中。
   - 人口至少 2 時依人口／陸戰隊／戰車數量加權受害者種類。
   - 人口少於 2 時優先在陸戰隊／戰車間抽選；無部隊才傷害最後殖民者。
4. 特殊命中全部完成後，必須再走一次現有 `ResolveStrategicColonyDamage` 的 1 點
   一般傷害，並同步人口群組、職務、部隊、建築效果、建造進度與殖民地平行陣列。
5. 玩家、熱座與 AI 必須使用同一 resolver。事件訊息只報告實際人口、部隊與建築
   損失，不再宣稱氣候惡化。

## 驗收

- 公式可產生 0 次特殊命中，但仍有 1 點一般傷害。
- Toxic／Radiated 不可被選；200 次失敗後選最高索引合格殖民地。
- Android 不會被特殊命中殺死；混居時只抽非 Android。
- Tolerant 玩家與 AI 均拒絕事件。
- 玩家與 AI 的殖民地刪除會同步所有平行陣列；熱座非目前席位結算後可往返保存。
- 氣候欄位與對應 planet 資料保持不變。
