# 格子戰術逐武器槽控制規格

## 證據邊界

- 已證實：原版戰術畫面顯示八個武器槽與綠／橘／紅三態；橘色略過下一次開火後恢復，紅色持續
  關閉；IDA `0x44D65..0x44D6B` 有 runtime `2 → 1` 寫回。
- 操作 adapter：remake 左鍵依「可用 → 待命 → 關閉 → 可用」循環；原版循環方向未知。
- 操作 adapter：右鍵以戰術訊息列顯示名稱、數量、傷害、射界、彈藥與改造；原版資訊彈窗的外觀與完整呼叫鏈未證實。
- 已接：紅色 PD 自動攔截例外由逐槽防禦規格處理；主動開火模式不再阻擋飛彈／戰機迎擊。
  證據與解算邊界見 tactical-point-defense-slots.md。

## Runtime 契約

1. `TacticalWeaponReady`：槽可參與下一次主動齊射。
2. `TacticalWeaponStandby`：槽略過下一次該艦成功齊射；若同艦至少一個其他 ready 槽真正開火，
   本槽在齊射後恢復 ready。
3. `TacticalWeaponOff`：槽不參與主動齊射，直到玩家切回其他模式。
4. `CombatShip.WeaponModes` 與 `WeaponMounts` 等長；舊單槽艦以一筆 ready 相容模式顯示。
5. 模式是本場戰術 UI 狀態，不寫回 `ShipBlueprint`、`.GAM` 或戰略存檔。

## 射擊契約

1. 多槽派送只遍歷 ready 槽；standby／off 不擲 RNG、不耗彈藥、不解除匿蹤。
2. 齊射至少有一發真正射出才算成功；全槽 standby／off 時顯示「沒有啟用的武器槽」且不結束艦艇
   行動。
3. standby 只在同艦本次成功射擊後恢復；射程、射界或彈藥使 ready 槽未能射出時不恢復。
4. 模式不得改變 `WorkingCount`、射界、彈架、mods 或艦級狀態。

## UI 與文字安全框

1. 使用原版控制列左側武器資訊區，八槽排成兩欄四列，不覆蓋中央 AUTO／SCAN 等按鈕。
2. 每列繪製、文字截斷、hover 外框與 hit region 共用 `tacticalWeaponSlotRect(i)`。
3. 文字包含槽號、武器名、工作數與有限彈藥；最長繁中／英文值必須截斷在欄內。
4. 綠／橘／紅之外另保留文字狀態（可用／待命／關閉），不能只靠顏色傳意。
5. 右鍵不改變開火模式，只在既有有界戰術訊息列顯示該槽明細。

## 驗收

- 單槽與多槽 deterministic 射擊測試。
- standby 一次恢復、off 持續、彈藥不誤扣、全停火不結束行動。
- 右鍵明細含傷害、彈藥與改造，且不改變開火模式。
- 八個安全矩形不重疊、不超出 640×480，且不碰中央控制列按鈕。
- Docker + Xvfb 正常戰術畫廊目視抽查繁中畫面。
