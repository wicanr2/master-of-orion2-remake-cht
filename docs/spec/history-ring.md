# 帝國歷史環規格

## 證據邊界

- **已證實**：`Record_History_ @ 0x10208A` 每回合寫入四個 350-byte 環：艦隊、科技、人口、建築；索引到 350 後歸零。
- **已證實**：四項各有最小值 1 的全局除數。任一帝國的當期原始值除後超過 250，就增加除數，並以 `舊值*舊除數/新除數` 重縮放既有資料。
- **已證實**：艦隊依每艘有效艦的 1-based 艦體級計 `10*2^class`；建築是各建築原版生產成本總和。
- **已證實**：科技讀玩家記錄 `+0x224` 的累積值；remake 沒有保存這個 raw 快取。
- **強推論**：remake 以已完成主題成本及 Hyper-Advanced 等級成本重建科技累積值；這不冒稱為原版 raw 寫入端已閉合。

完整 IDA Pro 證據見 [`../re/history-score-audit-20260825.md`](../re/history-score-audit-20260825.md)。

## Remake 契約

1. 指標及儲存順序固定為艦隊、科技、人口、建築。
2. 最多保留 350 回合；Go 採時間排序切片，達上限後丟最舊一格，玩家可見語意等同原版環。
3. 每回合先計算所有帝國，再共同調整各項除數；同一指標的帝國折線可直接比較。
4. 存檔保存四個除數。舊版的國庫／當回合研究欄位不相容，讀取時清除舊歷史，不能改名冒充原版資料。
5. 未知艦級安全回退最小艦級；無法對回原版 ID 的建築不計入原版建築指標。

## 驗收

- 251 在除數 1 時觸發除數 2，既有資料同步重縮放。
- 第 351 筆只保留最近 350 筆。
- UI 可循環四項，繁中與英文名稱完整。
- JSON 往返保存資料與除數；舊格式不產生偽造的科技／建築歷史。
