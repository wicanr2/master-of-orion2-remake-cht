# 玩家科技取得後的艦艇設計更新規格

## 觸發點

只在玩家實際取得一項科技應用後更新六筆 blueprint：

- 研究完成且科技已自動／創造性解鎖；
- 玩家完成待選科技的選擇；
- 間諜成功偷到科技。
- 遺跡／神器一次性發現直接授予研究主題。

單純切換研究主題、增加研究進度或重讀畫面不得觸發。

## 真人戰術分支

1. 維持六筆設計庫不變量。
2. 取得目前最高已解鎖裝甲索引。
3. 對 hull 0..5 只更新 `ShipBlueprint.Armor`。
4. 保留武器、護盾、特殊裝置、mods、arc、ammo、raw role、所有 `WeaponMounts` 尾端資料與
   `SpecialIDs`。
5. 目前 UI 顯示及之後 BUILD 立即讀更新後 blueprint；JSON、熱座與 TCP 走既有快照。

原版同時更新 warp drive、FTL speed 與衍生成本；remake 的引擎階及成本由當前科技即時計算，
不另存會漂移的衍生值。

## 建造中艦艇

remake 殖民地佇列沒有原版 status 4／6 的實體 ship record。完成交付時才建立艦艇，因此必須
使用當下設計／科技；不得為了模仿 raw record 另造一份不被玩家路徑使用的影子艦艇。

## 尚未納入

- 戰略戰鬥模式的六筆完整自動重建；目前新遊戲資料模型沒有該選項。
- AI hull 0..4 完整重建；AI 尚無逐艦與 blueprint 模型。
- 以上兩項維持 WORKLIST 缺口，不得把本規格標成整支原版函式完整 parity。

## 驗收

- 解鎖更高裝甲後六筆設計全部升級裝甲。
- 武器、特殊裝置、尾端 mounts 與特殊 raw ID 不變。
- 沒有新裝甲時結果逐值不變。
- 研究完成、科技選擇、間諜偷竊與神器授予四條玩家取得路徑各有測試。
- 快照往返及全套 Go 回歸通過。
