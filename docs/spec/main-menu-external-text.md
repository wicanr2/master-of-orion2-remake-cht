# 主選單外部文案與安全版面規格

## 文案契約

- 語言列、規則版本列及主選單相關轉場名稱全部由 `assets/i18n/ui.json` 提供。
- Go 只保存穩定 key、目前語言狀態與 `1.3`／`1.5` 動態值；不得保存玩家可見雙語句子。
- 原版六顆按鈕繼續以 `menu.json` 的原文 key 作 action／overlay 識別，不複製到 Go。

## 幾何契約

- 語言列 owner 為 `(12,428,220,22)`，規則版本列 owner 為 `(12,450,220,22)`。
- 每列文字安全框由 owner 水平內縮 8px、垂直內縮 3px，文字與點擊列共用整數像素中心。
- 正常語言名與 `1.3`／`1.5` 值必須完整顯示；異常超長版本值才確定性省略，不可越出畫布或
  進入相鄰列。

## 驗證契約

- 繁中、英文及最長版本值使用執行期 fallback 字型通過雙軸 containment。
- 兩列 owner、文字框與中心關係以測試固定；`menu()` source slice 不得再出現 `.tr(`。
- 本規格只驗證 remake 擴充，不宣稱原版存在相同控制。
