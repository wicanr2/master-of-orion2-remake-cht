# 戰略轟炸殖民地傷亡規格

證據來源：`docs/re/strategic-colony-casualties-audit-20260824.md`。

## 輸入與輸出

純規則接收殖民地人口、最後人口點數、陸戰隊、戰車、建造進度、raw building IDs、
各單位成本、可用傷害點數及可注入亂數函式。輸出更新後狀態、各類損失、摧毀建築 ID、
已消耗／剩餘傷害與殖民地是否毀滅。

所有負數輸入在 remake 邊界夾為零；重複、範圍外或無法對回 raw ID 的建築不進候選。
這是型別安全邊界，不冒稱原版壞資料行為。

## 解算契約

每輪重新建立候選池：

1. 可摧毀建築依 raw ID 48→1。
2. 每名陸戰隊一項。
3. 每輛戰車一項。
4. 建造進度非零時一項。
5. 人口不是一時，每單位人口一項。

使用 `intn(len(candidates))` 選一項：

- 建築：成本為版本設定值；足夠才移除。
- 陸戰隊／戰車：足夠支付該單位成本才移除。
- 建造進度尾端：依原版不對稱比較，通常一次清空全部進度；否則移除人口。
- 人口：移除一單位。

任何被抽中目標的成本高於剩餘傷害時，立即停止，不另抽較便宜目標。每次成功消費後
重建候選，直到傷害用完或候選為空。

人口等於一且其餘候選為空時，每輪最多消費 100 點扣最後人口點數；點數耗盡即人口歸零。
新建或舊版 remake 狀態沒有該點數時，安全預設為 100。

## shell 接線

- `BombardColony` 仍先依原版固定三外圈計算傷害，再用 `/40` 取得本規格的傷害池。
- 建築名稱必須用 `OriginalBuildingIDForName` 對回 raw ID；無法對映者保留，不猜測。
- 傷亡後同步 AI 殖民地人口、陸戰隊、戰車、建造進度及建築 map；人口職務總和若超過
  新人口，依工人、農夫、科學家的既有優先序縮減至合法總和。
- 生物武器在一般轟炸後另行結算；它不進本候選池。
- 防禦設施反擊與摧毀鏈仍是獨立系統，不得因本 helper 排除某建築就把它視為無敵或已摧毀。

## 最小驗收

- 候選順序與排除 ID 測試。
- 成本不足即停止；陸戰隊、戰車成本與損失測試。
- 建造進度尾端原版不對稱分支測試。
- 最後人口 100 點與殖民地毀滅測試。
- shell 端 raw ID 對映、狀態寫回、無法對映建築保留及存檔往返測試。
