# 隨機事件 8「艦船爆炸」規格

證據來源：[`../re/random-event-ship-explosion-audit-20260825.md`](../re/random-event-ship-explosion-audit-20260825.md)。

## 目標選擇

1. 事件沿用一般壞事件的帝國目標選擇。
2. 在目標帝國所有目前存在的艦艇間依原版掃描順序做 reservoir sampling：第 `n` 艘
   合格艦以 `1/n` 機率替換候選。沒有艦艇時事件不成立。
3. 一艘艦也可成為目標；不得加入「保留最後一艘」護欄。

## 結算

1. 移除且只移除所選艦艇；不得套用戰鬥引擎爆炸勢能、鄰艦連鎖傷害、艦級抗性或
   remake 尺度轉換。
2. 若所選艦艇有已指派軍官，該軍官一併死亡並從可用領袖清單移除，不得回人才庫，
   也不得繼續提供技能或維護費。
3. 玩家、非目前熱座席位與 AI 都使用同一選艦及軍官死亡語意；結果必須經既有
   JSON／熱座／多人快照自然往返。

## 顯示與驗收

- 雙語訊息必須包含被毀艦名稱；有軍官時亦包含軍官名稱及死亡結果。
- 固定亂數測試覆蓋 reservoir sampling、唯一艦可被毀、只移除一艘、無鄰艦傷害、
  軍官死亡、AI 與非目前熱座席位回寫。
- 搜尋並移除把事件 8 描述為 `Random(201)+74` 或三艘連鎖傷害的現況斷言；戰鬥引擎
  爆炸公式可保留在其正確子系統，但不得再由事件 8 消費。
