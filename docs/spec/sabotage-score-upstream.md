# SABOTAGE 帝國計分規格

## 目的

將原版兩張 runtime 表的共同能力值與派駐人數分開建模，並維持現有可存檔的逐對手 Spies／Agents 結構。

## 規則

1. 科技加成沿用五項已知間諜科技，總和逐項計算。
2. 種族共同基底為諜報特性數值加上心靈感應 `+10`。
3. 攻擊帝國能力加最佳 `Spy Master`；防禦帝國能力加最佳 `Telepath` 與目前政府防禦值。
4. 同技能多位領袖只取最佳值。
5. Spies／Agents 人數仍由 `SpySlotBonus` 在任務判定時加入，不得重複寫進帝國能力。
6. 最終任務仍使用 `E = T + DB - AB`；SABOTAGE 的 `T=70`。

## 驗收

- 純函式測試共同基底、攻擊／防禦分流與負政府值。
- 現有 SABOTAGE 測試須證明 slot、科技、種族、領袖與政府各只計一次。
- 文件不得再稱兩張表的上游未知或 runtime 值固定為 `0xFFFF`。
