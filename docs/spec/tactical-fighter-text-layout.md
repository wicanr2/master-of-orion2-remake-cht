# 戰術戰機文字與版面規格

## 證據邊界

- **已證實：**原版 `sub_3AC20 @ 0x3AC20`、`sub_3AD57 @ 0x3AD57` 與
  `sub_3D2DF @ 0x3D2DF` 是既有戰機攻擊／runtime 分流錨點；玩法公式沿用
  `docs/re/weapon-mod-flags.md` 的分級結論。
- **強推論：**中隊出擊、返航及主要目標狀態可用一個場上 token 清楚呈現。
- **remake 適配：**標題列右側的出擊按鈕、單 token 中隊圖示與摘要列不是原版
  逐架動畫或原版控制列，不得宣稱逐像素一致。

## 實作契約

1. 固定玩家文案全部由 `assets/i18n/ui.json` 提供；動態艦名及數字只作格式參數。
2. 出擊按鈕文字必須以 `launchRect()` 為唯一繪製及命中邊界，水平與垂直置中，
   溢位時由 `textSafeRect` 縮排／裁切。
3. 24×16 中隊 token 只容納外部化的單字元狀態 glyph 與動態架數；不得使用會
   超出 token 的完整型別名稱。
4. 繁中、英文的固定文案都不得回退成 Go 字串常數。
