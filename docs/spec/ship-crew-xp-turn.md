# 逐艦艦員經驗回合規格

證據來源：`docs/re/ship-crew-xp-audit-20260824.md`。

## 每回合規則

逐一處理玩家所有有效艦隊中的每艘船，不排除支援艦：

1. 基本經驗 `+1`。
2. 加上帝國有效 Instructor 領袖中的最大加成；多位不累加。
3. 艦隊靜止且所在星合法時，每座己方太空學院再 `+1`。
4. 把結果夾到 500。

航行中的船只有基本值與 Instructor，不取得太空學院加成。舊存檔或人工資料的負 XP
先視為零，再套本回合增量；已高於 500 的髒值在此 consumer 收斂到 500。

## 等級

一般種族的玩家可見門檻是 0／50／150／500，最高 Elite。Warlord 將同一階梯向上平移
一級，0 XP 起為 Regular，500 XP 為 Ultra Elite。raw 1000 門檻保留為原版資料證據，
但每回合 consumer 的 500 cap 使一般種族無法靠此路徑抵達該級。

## 驗收

- 499 加基本 1 後成為 500；500 再推進仍為 500。
- Instructor 與多座學院的合計也不得越過 500。
- 航行中不吃學院，但仍吃基本值與 Instructor。
- 殖民船／前哨船同樣累積 XP，避免錯用靠港修復的 COMBAT_SHIP 門檻。
- 50／150／500 邊界及 Warlord 平移保持既有測試。
