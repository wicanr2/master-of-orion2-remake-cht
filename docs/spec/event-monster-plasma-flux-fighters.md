# Plasma Flux 戰機中隊擴散規格

## 適用對象

- ID 44 啟動時，除雙方艦艇外也枚舉 `tacticalScreen.squads` 的雙方存活戰機中隊。
- 使用與艦艇相同的 96px 半徑、20px 格中心與距離平方衰減。
- 不按陣營過濾；射手是艦艇，不存在「排除射手中隊」問題。

## 迴避與傷亡

1. 每個中隊先擲 1-based `Random(2)`；結果 1 時整隊避開，不再消耗逐架骰。
2. 未避開時計算 `chance = 25×attenuatedDamage/max(1,HPEach)`。
3. 以啟動當下 `Alive` 為次數，每架各擲 1-based `Random(100)`；`roll<=chance` 就損失一架。
4. 球形武器直接減少架數；倖存者 `HPEach` 不變。降至零的中隊沿用既有 dead/drop 流程。

## 資料模型限制

- 原版同一分支也掃描在途飛彈 record；remake 飛彈為同步命中解算，沒有場上位置或生命週期，
  本規格不得憑空建立只供 Plasma Flux 使用的飛彈 record。若日後建立通用在途飛彈模型，須以
  獨立 RE→spec→實作切片接回。

## 驗收

- 50% 迴避成功時不減員且不消耗逐架骰。
- 未迴避時依單架耐久與衰減傷害逐架判定。
- 格子戰術證明雙方圈內中隊都可能受損，圈外中隊不受影響。
