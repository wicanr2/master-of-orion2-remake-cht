# 殖民地政體產出規格

## 規則

1. 每人口基礎食物／工業／研究率不得因套用政體而被永久改寫。
2. 每回合依目前生效政體建立逐職務百分點：
   - 統一：食物、工業 `+50%`。
   - 銀河統一：食物、工業 `+100%`。
   - 封建／邦聯：研究 `-50%／-25%`。
   - 民主／聯邦：研究 `+50%／+75%`。
3. 政體百分點與人口士氣、重力、prisoner 及相應領袖技能在同一次整數產出公式中合併，
   不可逐項相乘並重複取整。
4. 統一兩級忽略一般士氣修正，但仍保留逐種族基礎率、重力、prisoner 與領袖技能。
5. 玩家取得進階政府科技後，下一次衍生值重算立即改用進階表。AI 依自身原版種族政體及
   已取得的進階政府科技使用同一套欄位。
6. 舊 JSON 缺少新欄位時零值安全；欄位由回合前同步重建，不依賴持久化殘值。

## 驗收

- 重複套用同一政體不改變三個基礎每人口率。
- 統一只提高食物與工業；聯邦只提高研究。
- 政體八格研究修正依序為 `-50,-25,0,0,50,75,0,0`。
- typed population groups 與舊狀態 fallback 均消費相同政體百分點。
- 玩家與 AI 正常回合都在經濟結算前同步政體欄位。
