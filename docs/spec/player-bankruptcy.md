# 玩家負國庫資產處分規格

## 範圍

當本回合收入與全部維護費結算後使玩家國庫為負，立即執行原版已證實的強制拆船、建築出售、
間諜裁撤與領袖解雇。`player+0x59D` 是 AI 晚期科技鏈旗標，不屬於真人玩家處分流程。

## 處分順序

1. 依原版固定呼叫矩陣處理前哨船、運輸艦、戰鬥艦與殖民船。每個 pass 可要求：
   - 艦艇位於己方殖民地／前哨支援星；
   - raw mission 屬於 `0／3／7`。
2. 每個 pass 反覆拆到國庫非負或沒有候選；友軍支援星退款 `ProductionCost / 4`，其他位置
   退款 0。戰鬥艦選最弱者，支援艦同分時沿用原版最高索引優先。
3. 拆船 pass 與原版建築 ID／raw category 的三輪候選篩選交錯：
   - 成本正值、category 非 1／3、ID 非 9；
   - 成本正值；
   - ID 非 9。
4. 建築每次選目前價值最低的候選；remake 同值以殖民地索引、原版建築 ID 形成穩定順序。
   出售後返還 `ProductionCost / 2` BC 並移除可逆效果。
5. 指定拆船／建築段仍不足時，依對手槽裁撤間諜，再補做戰鬥艦、依領袖池解雇有維護費的
   領袖，最後執行第三輪建築。
6. 國庫已非負立即停止；全部可處分資產耗盡仍為負時保留負值，不憑空補錢。

## 狀態與摘要

- `LastBankruptcy` 是不進存檔的本回合報告，記錄建築、艦艇、間諜、領袖及回收 BC。
- 每次回收同步修正 `Player.BC`、`LastPlayerOutput.Player.BC` 與 `LastPlayerOutput.NetBC`。
- 間諜／領袖裁撤同步調低本回合輸出的維護費分項，確保摘要加總與國庫差額一致。
- 建築效果移除必須反向撤銷所有可逆增量與旗標；行星護盾曾造成的氣候改善屬已發生的世界狀態，
  不因出售護盾倒退氣候。

## 驗收

- 拆船艦種／友軍位置／mission 邊界、四分之一與零退款有 shell 測試。
- 三輪建築篩選與原版 ID 9 邊界有純規則測試。
- 半價退款、最低價值選擇、可逆建築效果、間諜與領袖順序有 shell 測試。
- 無資產時保留負國庫。
- 正常國庫時完全不改狀態。
