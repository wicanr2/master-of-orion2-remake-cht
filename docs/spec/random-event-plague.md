# 隨機事件 16 瘟疫規格

證據來源：[`random-event-plague-audit-20260825.md`](../re/random-event-plague-audit-20260825.md)。

## 建立

1. 從目標帝國殖民地均勻抽一次；抽不到或同一行星已有互斥事件即不適用，不得改抽。
2. 讀取該殖民地當回合研究產出 `R`；`R < 1` 時不建立。
3. 擲 `d = Random(8)`，研究需求為 `R × (d + 2×difficultyRaw)`。
4. 建立當回合只播報，不立即扣人口或增加治療進度。

## Active 效果

- 目標殖民地每個一般人口群組的成長百分點減少 200；使用既有 signed growth 回寫人口。
- 每次帝國經濟結算後，把目標殖民地實際 Research 加入治療進度。
- 進度達需求即解除；Research 為 0 的回合進度不變。
- status 4 的隨機中途播報不解除瘟疫，也不改公式。

## 路徑與驗收

- 玩家、熱座與 AI 使用相同需求公式、負成長及治療進度。
- 加成只存在於回合輸入副本，不永久修改 `GrowthBonusSum`。
- 保存種類、目標行星、需求、完成進度與 age。
- 測試三組難度／骰值、`-200` 百分點、研究解除、事件互斥及 AI 副本。
