# Plasma Flux 格子戰術擴散規格

## 範圍與幾何

- ID 44 一次啟動消費該 mount 的全部 `WorkingCount`，不是逐門各播放一次範圍效果。
- 以射手格中心為原點；每格 20 像素、半徑 96 像素。使用歐氏距離平方且包含邊界。
- 枚舉雙方所有存活 `CombatShip`；排除射手本身，不依陣營排除友軍。

## 傷害

1. 每門武器各在 mount 的 min..max 間擲一次，總和為中心基礎傷害。
2. 每個目標算 `attenuated = total × (100 - 100×distanceSquared/radiusSquared) / 100`，
   最低為 1。
3. 重複 `target.SizeClass+1` 段；每段先擲 1-based `Random(attenuated)`，若 `<=1` 取 1，
   否則再擲一次同範圍並累加。
4. 合計傷害按射手到目標的護盾朝向，依球形武器既有護盾、裝甲、結構順序套用。

## 驗收

- 釘住 96 像素半徑、歐氏平方邊界與距離衰減。
- 證明射手不自傷、敵對目標及同陣營鄰艦都會受傷、圈外艦不受影響。
- 證明一次 mount 啟動只產生一次範圍結算，尺寸分段使用可重播亂數。
- 一般球形武器與 Caustic Slime 路徑不得改變。
