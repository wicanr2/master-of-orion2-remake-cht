# 領袖／軍官管理外部文案規格

## 文案契約

- 操作回饋、目標、雇用模式、名冊模板、任命狀態、空池提示與轉場名稱全部由 `assets/i18n/ui.json` 供應。
- Go 只保存 action、typed 狀態、領袖／艦艇名稱及數值參數；技能顯示名沿用 `leader_skills.json`。
- 選取與候選標記也是 catalog 資料，不在 Go 內嵌 glyph。

## 幾何契約

- 頂部目標與操作回饋各有獨立安全框，不得侵入第一列任命狀態；HIRE 狀態由操作回饋呈現，
  不另畫會與第一列相撞的常駐提示。
- 四列的姓名、技能／等級與右側任命狀態各自限制於該列；長名稱以省略號截斷。
- 不在 y=441 底部按鈕列上方另畫名冊提示。

## 驗證

- 雙語所有鍵可解析，最長實際模板與極長動態名稱通過 runtime 字墨 containment。
- 四列安全框不得超出各自 108px 列界，也不得碰到底部按鈕列。
- `officer()` source slice 不得出現 `.tr(` 或直接內嵌選取 glyph。
