# 元件顯示名稱外部目錄規格

## 資料契約

- 六個 `TECH_NONE` 元件各有一個 `component.label.*` 語意鍵，中英文顯示文字只存在 `assets/i18n/ui.json`。
- Go 程式可保存既有中文規則鍵，以維持查表及存檔相容；不可保存對應的玩家顯示字串。
- 有 `UnlockTech` 的英文顯示名稱讀原版科技名稱表，不複製第二份元件譯名表。
- 無法辨識的 `TECH_NONE` 元件使用 `component.label.unknown`，英文模式不得回退成中文規則鍵。

## 驗證契約

- 六個外部目錄鍵在兩種語言均不得缺值。
- 所有正式元件在英文模式不得含漢字。
- 人工建立的未知無科技元件必須得到語言相符的安全 fallback。
- `componentlabel.go` 不得內嵌六個中英文顯示值。
