# 人口成長點數尺度規格

## 適用範圍

本規格只定義人口成長點數的單位、複製中心固定加成、整格人口兌換與存檔不變量。多種族逐族
成長、AI 難度加成及原版事件分支不在本切片內。

## 規則

1. `gamedata.PopulationGrowthPointsPerUnit` 固定為 `1000`；累積滿 1,000 點增加一個人口單位。
2. `gamedata.CloningCenterGrowthPoints` 固定為 `100`，在百分比成長截斷後加上，且人口已達上限時
   不再產生固定成長。
3. 種族成長百分比只套一次；目前由 `shell.advancePopulation` 消費 `raceGrowthPct`。
4. `popAccum` 保存原始成長點數。更正門檻不改變點數單位，因此 JSON 存檔版本保持不變，載入時
   不縮放既有值。
5. 每次兌換 1,000 點後呼叫既有職務指派，人口不得超過 `PopMax`；達上限時保留不足一格的餘數，
   不繼續兌換。

## 驗收

- 999 點不增人口；再加入 1 點後恰增一人口並把餘數歸零。
- 快照還原前後 999 點完全相同，不發生 300→1000 比例遷移。
- 複製中心提供 100 點，而非舊調校值 30 點。
- 既有 30 回合人口成長、人口上限與職務總數測試仍通過。

證據與限制見 `docs/re/population-growth-scale-audit-20260824.md`。
