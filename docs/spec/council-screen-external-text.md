# 銀河議會畫面外部文案與版面規格

1. `council()` 不得呼叫 `tr` 或保存固定玩家句子；固定文案及模板使用 `council.*` JSON 鍵。
2. 候選人、帝國名、票數、回合與屆次是格式參數，不複製進 catalog。
3. 玩家投票三個標籤的安全框必須由 150×40 熱區推導；接受／拒絕文字框由 400×26 熱區推導，文字中心與點擊中心一致。
4. 標題、摘要、投票明細各使用不相交的 `textSafeRect`；最長雙語內容只能換行或省略，不得越出 640×480 畫布或侵入操作列。
5. 測試必須驗證雙語鍵、格式參數數量、熱區／文字框中心及 `council()` 無 `.tr(`。
