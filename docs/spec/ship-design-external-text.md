# 艦艇設計外部文案與安全排版規格

## 文案契約

- 建造拒絕、轉場、艦體成本、元件類別／效果／成本、射界、彈藥、槽、總價、國庫、解鎖、空間與改造標題全部由 `ui.json` 提供。
- 控制項 glyph／ADD／DEL 與目前艦體標記也屬玩家文字，必須由 JSON 供應。
- 元件、射界與改造名稱保持 typed 資料的既有顯示邊界，本切片不改規則識別鍵。

## 幾何契約

- 四個元件列、射界、彈藥、總價、國庫各有獨立安全框。
- 六個不等高原版艦體槽旁的價格使用六條連續 16px 安全列；不改原槽熱區，列中心誤差最多 1px。
- 解鎖摘要或建造錯誤共用固定兩行框；空間標題與 3×2 空間表固定於改造區上方。
- 改造標題與每個 chip 都使用安全框，文字與命中框不得漂移。

## 驗證

- 雙語最長模板、未知原版裝備、六位數價格、長艦體／元件／改造名通過 runtime containment。
- 固定資訊區不得互相重疊或進入 `y=350` 起的改造標題區；chip 不得超出 `y=431` 下邊框。
- `shipDesign()` source slice不得出現 `.tr(`。
