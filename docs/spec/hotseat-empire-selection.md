# 熱座真人帝國選擇轉接介面規格

## 目標與證據邊界

原版會從帝國陣列的控制與狀態欄位計算真人席位；證據見
`docs/re/hotseat-empire-selection-audit-20260827.md`。remake 先生成玩家與 AI，故在
名稱／旗色之後加入清單，讓玩家明確指定哪些 AI 帝國改由其他真人接管。這是
資料模型轉接，不是原版畫面的精確重建。

## 行為契約

1. 需求數為 `pendingHotseat - 1`，預設選取前 N 個 AI，但玩家可改選任意 N 個。
2. 選取數達上限後，不得再增加；取消既有選取後才可選另一個帝國。
3. 確認只在選取數等於需求數時生效，並將精確 AI 索引交給
   `SetupHotseatWithAIIndices`；返回則不套用接管。
4. 種族名稱使用 `assets/i18n/ui.json` 的 `race.select.race.*.name`；動態帝國名只在
   無法對應內建種族時作資料後備。

## 文案與版面契約

- 所有固定玩家文案、格式字串、轉場名與錯誤訊息均由 `assets/i18n/ui.json` 的
  `hotseat.empire_select.*` 鍵供應；Go 不得內嵌中英文句子。
- 標題、說明、計數、每列勾選標記、帝國標籤與兩顆按鈕都必須透過
  `textSafeRect` 繪製；安全框與滑鼠熱區共用相同整數像素中心。
- 單行內容超寬時截斷於安全框內，不得侵入相鄰列、邊框或畫布外。

## 驗證

- 雙語資源鍵存在，格式參數數量一致。
- 以長種族／帝國名稱抽查所有安全框，並以靜態測試禁止 `.tr(`、直接字型繪製與
  已知固定玩家句子重回 `hotseatselect.go`。
- 抽樣繪製繁中與英文畫面；規則測試確認改選後交出的 AI 索引精確。
