# 隨機事件 4／5「外交暗殺／外交聯姻」規格

證據來源：[`../re/random-event-diplomatic-incidents-audit-20260825.md`](../re/random-event-diplomatic-incidents-audit-20260825.md)。

## 適用條件與目標

1. 一般事件排程先選受害帝國；結算再按執行期帝國槽序掃描其餘存續且可表示外交關係的帝國，
   以 `Random(candidateCount)==1` 做 reservoir sampling。
2. 抽出第二帝國後才檢查正式狀態；不是 `DIPLO_LIMITED_WAR` 或 `DIPLO_WAR` 時，整個事件候選
   失敗，不得在剩餘戰爭對象中重抽。
3. 通過檢查的第二帝國必須同時供關係回寫與雙語新聞使用，不得重新抽取不同對象。

## 關係結算

1. 事件 4 使用原版 raw 基礎增量 `-100`；事件 5 使用 `+100`。
2. 在 `-100..100` raw 尺度依目前關係、actor 政體與第二帝國 Charismatic 旗標執行
   `Change_Relations_` 的事件可達調整，再夾值。
3. 因配對仍處於正式戰爭，結算值不得高於 `-25`；事件不自行簽訂和平或修改條約。
4. remake 持久關係採 `-40..40`，故運算前後以 `5/2` 與 `2/5` 轉換；玩家／AI 關係與
   AI／AI 對稱矩陣都必須回寫並自然進入 JSON／多人快照。

## 資料模型邊界與驗收

- 真人熱座席位彼此尚無外交矩陣，不可捏造不可保存的關係；可選對象限於目前可表示的
  真人／AI及 AI／AI 戰爭配對。
- 測試覆蓋：和平配對抽中後不適用、單一戰爭配對、reservoir 可重播、事件 4／5 raw 邊界、
  Charismatic／政體分支、玩家／AI、AI／AI 對稱回寫，以及事件 5 戰爭上限 `-25 → -10` 投影。
- 1.50 仍標未知，不以 1.31 測試宣稱跨版本逐值一致。
