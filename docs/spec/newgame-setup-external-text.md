# 新遊戲設定外部動態文案規格

1. `ngSettings` 與 `newGameSetup()` 不得呼叫 `tr` 或保存固定玩家句子。
2. 星系大小模板、帝國數模板與轉場名稱由 `newgame.*` JSON 鍵提供；大小名、星數與帝國數只作參數。
3. 五個動態值全部沿用 `ngStripTextRect`，文字中心與 100×20 選擇器熱區一致；最長雙語值必須能由 12／11／10px 策略放入高度 16px 的內容區。
4. 不改原版值圖資產、選項數、循環行為、版本背景 fallback 或開局規則。
5. 測試驗證雙語鍵、格式參數、五個安全框中心／包含關係及 source slice 無 `.tr(`。
