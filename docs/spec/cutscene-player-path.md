# Smacker 過場玩家路徑規格

## 行為

1. 影片依 Smacker header 的尺寸與 frame rate 播放；播放完成後進入指定下一畫面。
2. 正常互動模式下，任一剛按下的鍵或滑鼠左鍵放開都立即進入下一畫面。
3. 過場畫面只呈現影片與必要黑邊；不得疊加原版不存在的固定「跳過」提示。
4. 片頭下一畫面名稱與結局下一畫面名稱由 `assets/i18n/ui.json` 提供，不在 Go
   內保存固定玩家語言字串。
5. 資產缺失或解碼失敗不阻擋主選單／最終得分路徑。

## 驗收

- 純邏輯測試分別注入滑鼠、任意鍵及空輸入，驗證只有前兩者跳過。
- 靜態測試禁止 `cutscene.go` 出現 `.tr(`、直接字型繪製及舊跳過提示。
- 畫廊抽查片頭與結局 frame 不含額外提示；音軌依 `cutscene-audio.md` 驗證，不以畫面測試代替。
