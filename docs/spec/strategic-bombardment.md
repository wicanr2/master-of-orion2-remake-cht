# 戰略轟炸快速結算規格

1. 戰略轟炸固定執行三個外層攻擊回合；不得由版本 profile 把所有武器改成 5／10 回合。
2. 每個外層回合依現有 `Ship` 單武器模型，對每艘艦艇執行其武器類別的命中／傷害解算。
3. 炸彈是版本特例：1.31 使用 5 次攻擊當量，1.50 使用 10 次攻擊當量；此值不得影響光束、
   飛彈、魚雷、球狀或其他特殊武器。
4. 行星護盾仍逐次攻擊扣減，不得改成總傷害後只扣一次。
5. 累積傷害超過原版 30,000 停止門檻後不得再抽亂數或增加傷害；runtime hit 為累積值整數除以
   40。手冊 UI 的 `/100` Estimated Bomb Hits 不得用於實際結算。
6. 測試至少涵蓋：非炸彈兩版本同為三次、炸彈 5／10 當量、逐擊護盾、30,000 停止、`/40`
   邊界與固定 RNG。

逆向證據見 `docs/re/strategic-bombardment-audit-20260824.md`。
