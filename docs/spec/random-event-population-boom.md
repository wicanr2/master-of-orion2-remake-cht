# 隨機事件 17 人口暴增規格

證據來源：[`random-event-population-boom-audit-20260825.md`](../re/random-event-population-boom-audit-20260825.md)。

## 建立

1. 從目標帝國全部殖民地均勻抽一次。
2. 抽不到、人口已達上限或同一行星已有 active 人口暴增時，事件不適用；不得改抽另一座。
3. 建立時只記錄目標並播報，不立即增加人口。

## Active 效果與期間

- 從下一次帝國經濟結算起，目標殖民地的每個一般人口群組成長百分點增加 100；固定成長
  （例如複製中心）不乘這個加成。
- 前五個 active turn 不得結束；第六個起每回合 `Random(20)==1` 結束。
- age 超過 20 時仍先消耗一次 `Random(20)`，若未擲中也強制結束。
- 事件結束後立即停止加成，不修改殖民地保存的 `GrowthBonusSum`。

## 路徑與驗收

- 玩家、熱座席位與 AI 都能成為目標；效果只依目標行星套用。
- JSON 保存種類、目標行星與 age。
- 測試單次抽選失敗、`+100` 百分點、永久狀態不受污染、最短／最長期間與 AI 回合副本。
