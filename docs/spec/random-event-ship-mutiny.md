# 隨機事件 13「艦艇叛變」規格

證據來源：[`../re/random-event-ship-mutiny-audit-20260825.md`](../re/random-event-ship-mutiny-audit-20260825.md)。

## 原版相容行為

1. 事件仍可經一般壞事件候選與帝國目標選擇產生新聞播報。
2. 結算成功但不改變任何艦艇所有權、艦艇數量、艦艇設計、軍官、外交、國庫或殖民地狀態。
3. 不擲選艦或接收帝國亂數，也不以 remake 資料填補原版未初始化的 record 欄位。
4. 玩家、非目前熱座席位與 AI 目標使用相同無效果語意；訊息只描述收到叛變通報，不虛構
   艦名或接收帝國。

## 驗收

- 玩家直接結算前後的艦隊與 AI 艦艇不得改變。
- AI 目標與非目前熱座席位結算均成功播報，但各帝國艦隊不得改變。
- 原有「所有事件都必須改變狀態」測試不得再把事件 13 當成艦艇損失案例。
- 文件必須明列 1.50 二進位尚未核對，不把 1.31 的 bug 投影冒稱為所有版本已證實。
