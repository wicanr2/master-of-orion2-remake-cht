# 隨機事件 25「時空異象」規格

## 建立

- 先依一般壞事件權重選受害帝國，再在其 active 殖民地中 reservoir sampling 目標星。
- 目標星若已有彗星、瘟疫、人口暴增、海盜活動、超新星或時空異象，建立失敗。
- 建立 `PersistentStasis{StarIndex, Turns:-1}`；`Turns` 表示原版 active age，公告回合不先
  偷加一歲。玩家、非目前熱座席位與 AI 都可成為目標。

## 凍結效果

- 該星所有 owner 的殖民地停止食物、工業、研究、建造、自然成長與職務／人口轉移。
- 不消耗食物、不支付殖民地建築維護；原始人口、職務、建造佇列與建築資料保持不變，解除後
  可恢復。
- 玩家、熱座與 AI 的回合輸入都使用同一 `StarInStasis` gate；不得只修目前玩家畫面。

## 解除

- active age 0..4 不擲骰。
- age 5..20 每回合擲 `Random(20)`；只有 1 結束。
- age 21 強制結束，不依亂數。
- consumer 最後才增加 age；remake 因 `advancePersistentEvents` 先遞增，建立時用 `Turns=-1`
  對齊首次 consumer 的 age 0。

## 驗收

1. age 4／5、roll 1／2、age 20／21 邊界測試。
2. 玩家、AI、非目前熱座席位各一條目標建立與凍結測試。
3. 食物、工業、研究、成長、維護與建造均為零，但原始殖民地資料不被清空。
4. 同星多 owner 一起凍結；解除後下一回合恢復。
5. 互斥事件、JSON 往返、全專案測試、格式、擁有權與 Docker 清理通過。
