# 艦艇靠港修復規格

證據來源：`docs/re/ship-repair-audit-20260824.md`。

## 玩家路徑規則

每回合修復階段逐一走訪玩家所有艦隊。只有同時符合以下條件的艦艇可完整修復：

1. 艦隊沒有航行（remake 對 raw `Status == 0` 的近似）。
2. 艦隊所在星索引合法。
3. 該星是玩家修復基地；殖民地為強推論，前哨站目前也是強推論。
4. 艦艇是戰鬥艦；殖民船、前哨船及未來的運輸支援艦不得進入靠港修復 consumer。
5. 艦艇目前確實有損傷。

通過後把 `Ship.Damage` 清為零。回傳值只計算原本有損傷且確實被修好的戰鬥艦。

## 資料模型限制

原版會同時修復八個武器槽、五 bytes 特殊裝置旗標、護盾、引擎、電腦、裝甲與結構。
remake 目前只有合併的 `Ship.Damage`，因此本規格只完成可表示的結構／裝甲聚合寫回；
不得把這個結果宣稱為完整逐系統損傷 parity。

## 驗收

- 自家殖民地的受損戰鬥艦完整修復。
- 同一艦隊內受損殖民船／前哨船保持原損傷。
- 航行中、無主星或敵方星不修復。
- 前哨站修復行為保留，但測試及文件標示為強推論。
- 多艦隊各自判定，存檔往返不會遺失未被修復的損傷。
