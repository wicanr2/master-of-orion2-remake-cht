# 研究突破與進度回寫規格

## 回合規則

1. 目前研究 field 為 0（沒有有效研究主題）時不累積、不擲骰，也不補發起始科技。
2. 將本回合正研究產出加到目前累積進度。
3. 累積進度小於或等於成本時，突破率為 0，不擲骰。
4. 累積進度大於成本時：
   `chance = clamp(floor((progress-cost)*100/cost), 1, 100)`。
5. 本回合研究產出必須大於 0 才擲一次 1..100；`roll <= chance` 即完成。
6. 失敗保留完整累積進度；成功把進度清零，不結轉超額研究，並進入既有科技應用授予流程。

## 亂數與保存

- engine 不建立全域 RNG；正常 shell 注入可保存的研究亂數流。
- roller 只能在第 4、5 點均成立時消費，剛好達成本、零產出或無主題不得推進亂數位置。
- 玩家、熱座席位及 AI 使用同一個 session 研究流，確保存讀檔重播一致；這是 remake 的
  可重播 adapter，不宣稱與原版全域 LCG 使用相同 seed／抽取序列。

## 驗收

- 成本 400 的 400／401、440、799、800 邊界有純規則測試。
- 10% chance 的 roll 10 成功、11 失敗；失敗保留進度、成功清零。
- 剛好成本及本回合零研究不呼叫 roller。
- 正常玩家 `EndTurn`、熱座與 AI 的帝國結算均注入研究 roller。
- Creative／Uncreative 應用選擇沿用既有測試，但不得以其通過宣稱原版選項時序已閉合。
