# 殖民地主畫面外部文案與版面規格

## 文案契約

- `colonyscreen.go` 僅保存座標、typed action、數值與 `colony.*` 語意鍵；玩家可見
  標題、按鈕、產出模板、同化、人口、建築狀態與職業文字統一放在
  `assets/i18n/ui.json`。
- 行星資訊中的礦產／重力前綴及未知值也走外部文案；行星、建築和 Special 的
  typed 名稱仍使用既有資料表翻譯，不複製到 `ui.json`。
- 中文模式擦底疊字；英文模式有 `COLPUPS.LBX#5` 時露原版烘字。缺少框架資產時，
  兩種語言皆由外部文案繪製後備按鈕。
- 轉場標籤亦用語意鍵，避免中文識別字藏在玩家流程程式內。

## 雙軸安全框

- 左欄標題高 18；環境清單依既有多行框；同化與人口各高 16，互不重疊且不超出
  `(7,28,109,121)` 面板。
- 中欄兩列產出各高 16；Buildings 標題高 16，建築清單從其下緣開始。
- 職業列維持原版 y=`62+30i`。12px 點陣字墨需要至少 16px，高度改為 18；三個
  子欄不得跨越 x=`310..510` 或下一列。
- 按鈕安全框水平內縮 3、垂直內縮 1，中心必須與熱區中心一致。不可再使用
  「外框先縮 3，再以 inset 重複縮一次」的雙重內縮。
- 所有動態文字必須經 `textSafeRect`，禁止在 `colonyscreen.go` 直接呼叫字型
  `Draw*` 或重新加入 `.tr(`。

## 驗收

- `colony.*` 鍵在繁中／英文均可解析。
- 代表性最長殖民地名、同化數值、產出、按鈕、職業與建築空狀態在 runtime
  bitmap font 下收束於安全框。
- 幾何測試驗證按鈕文字中心等於熱區中心、職業列不交疊、左中右面板不越界。
- 既有殖民地互動與完整 `go test ./...` 必須通過；這只證 remake 回歸，不等於原版 parity。
- 畫廊的新局正常路徑必須先通過「選擇研究 application」gate，再第二次按 TURN；
  不得只按一次 TURN 後依固定 tick 把同一研究畫面存成事件、艦隊或殖民地檔名。
- 原版一般事件至少要到第 50 回合；短畫廊不得把固定種子誤稱為第一回合事件。
  `06_turnsummary.png` 取自正常第一回合，`05_event.png` 使用外部 JSON 雙語文案的
  固定戰報，只驗證事件視窗版面，不作玩法一致性證據。
