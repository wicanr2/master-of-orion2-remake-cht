# 連線玩家名冊外部文案與安全框規格

## 證據邊界

- **已證實**：`Choose_Network_Plyrs_Screen_ @ 0xF0E17` 依列數計算視窗高度；
  `Add_Choose_Net_Plyrs_Fields_ @ 0xEFB50` 的列熱區為
  `x=winX+0x6A..winX+0x1B3`、`y=winY+0x40+i*0x24`、高 `0x1D`。
- **強推論**：標題與玩家列應以上述面板及熱區為文字安全框；原版字串與精確字墨錨點
  尚未形成完整匯出，因此 remake 的框內置中屬版面轉接，不宣稱逐像素一致。
- **現代轉接**：TCP 位址、共同種子與底層錯誤是 remake 網路層資訊，不冒稱原版 IPX 文案。

## 文案契約

所有固定可見文字、格式模板、預設玩家名及畫廊示範名稱由
`assets/i18n/ui.json` 的 `netroster.*` 鍵提供。Go 程式只保存語意鍵、玩家輸入、網路位址、
種子與底層動態錯誤，不保存中英文句子。

## 版面契約

- 中文標題限於 `240×26` 標題牌並置中。
- 每列列號與玩家名稱分框；名稱框採左右各 8 px 內縮，超長內容顯示省略號。
- 位址／等待提示與種子／錯誤各占一個 15 px 高安全框，不得跨入另一行或畫面下緣。
- 英文有正版標題烘字時維持原圖，不重複覆寫。
