# End Of Turn Wait 重製規格

## 狀態

- `sceneBuilder.continuousTurns`：只存在 UI adapter，不進存檔與網路狀態。
- `continuousTurnAt`：下一次自動推進的 `animTick`；固定間隔 15 tick。
- 只允許單人、非網路鎖步對局啟動。

## 啟動與停止

1. 玩家按 TURN 時先執行一回合。設定為 false 且可連續時，標記連續模式。
2. 一回合結算後若進入研究選擇、勝負過場／得分、GNN／勘查快報或回合摘要，立即清除連續模式。
3. 沒有中斷畫面時回星圖，15 tick 後自動執行下一回合。
4. 左鍵或右鍵在任何位置放開時，立即清除連續模式並消耗該次點擊。
5. 設定重新開啟、熱座或網路對局都不得保留連續模式。

## 文字

- 本切片不需要新增玩家文案；既有 SETTINGS 說明來自 `ui.json`／`help.json`。
- 不在 Go 加入狀態提示自由字串。

## 驗證

- 純狀態測試：設定開／關、單人／熱座／網路啟動資格。
- 路由測試：一般空回合保持連續；研究、勝負、快報、摘要會停止。
- 輸入測試：停止點擊不傳入下層畫面。
- 完整 Ebitengine 測試與中文畫廊不得退化；gallery／promo 腳本不得自行啟動連續模式。
