# 軌道轟炸外部文案與版面規格

## 文案契約

軌道轟炸畫面的標題、四列戰報、按鈕、轉場與錯誤全部來自
`assets/i18n/ui.json` 的 `bombing.*` 鍵。Go 只保留穩定鍵、格式參數與動態殖民地名；
不得使用 `tr(中文, English)`、字串串接分隔符，或在畫面函式內嵌玩家文案。

## 文字安全框

- 標題：`(10,2,620,34)`，水平置中，中心 y=19，是原版 `(319,10)`
  上緣錨點加上 18px bitmap 字實際高度後的 remake 安全框。
- 戰報面板：`(0,60,640,118)`；四列安全框為 `(12,70+24×row,616,24)`。
  生物武器列取代一般人口列，不產生第五列。
- 繼續按鈕：可見外框與熱區均為 `(265,432,110,30)`；文字框與它共用同一
  整數像素中心，只在內部保留水平 5px、垂直 1px 邊界。

所有文字均由 `textSafeRect` 量測後繪製；單列過長時使用可重現截斷，不依賴 painter clipping。

## 資產與後備

- 有正版資料時使用 `COLONY.LBX#8` 累積幀，palette provider 現為 `COLBLDG.LBX#0`。
- 紫色三階至守方旗色的映射是明示的 remake 視覺近似，不冒稱原版表格。
- 缺檔、空 frame 或 palette 解碼失敗時回到自繪深色背景，仍可完成戰報與返回星圖。
