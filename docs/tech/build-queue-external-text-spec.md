# 建造佇列外部文案與版面規格

## 文案契約

- `cmd/moo2/buildqueue.go` 只保存 typed action、資產索引、座標與 `buildqueue.*`
  語意鍵；所有玩家可見中英文及格式模板存於 `assets/i18n/ui.json`。
- 六顆按鈕有原版框架時，英文模式露出 `COLBLDG.LBX` 烘字；繁中模式以同一按鈕
  中心擦底疊字。資產缺失時兩種語言都必須由外部文案繪製可用後備按鈕。
- 建築與 Special 名稱沿用 typed gamedata 翻譯；Housing、Trade Goods 兩個 shell
  識別值由外部語意鍵顯示，不把英文名稱寫在 Go switch 中。
- AUTO BUILD 固定優先序與 REPEAT BUILD 限制必須在 JSON `note` 標為 remake 行為。

## 文字安全框

- 可建清單：每列位於 x=16..181，列距 19，高 16。
- 七格佇列：每列位於 x=210..455，列距 20，高 16。
- 按鈕文字框由原按鈕矩形水平內縮 3、垂直內縮 1；文字中心必須與熱區中心一致，
  且為 11px 點陣字墨保留至少 16px 高度。
- 標題、操作提示與狀態分別限制於 `(210,136,250,20)`、
  `(210,160,410,16)`、`(210,180,250,16)`。
- 狀態訊息不得沿用舊 `(210,470)` 起點。新框固定為 `(210,204,410,36)`、
  兩行、行距 17；它位於七格佇列上方，也不與 y=447 的 CANCEL／OK 重疊。
- 所有欄位使用 `textSafeRect` 的裁切／折行策略；不得直接呼叫字型 `Draw*`。

## 驗收

- 雙語 catalog 鍵完整，代表性最長訊息可在兩行框內收束。
- 六顆按鈕兩種語言均位於各自安全框，且安全框中心等於熱區中心。
- 靜態測試禁止 `buildqueue.go` 出現 `.tr(`、直接字型 `Draw*` 或代表性玩家句子。
- 保留既有 AUTO／REPEAT 熱區規則測試，並跑完整 `go test ./...`。
