# Expanding Help 重製規格

## 玩家契約

1. SETTINGS 每一列可用滑鼠右鍵開啟該選項的情境說明；左鍵仍只切換設定。
2. `ExpandingHelp=true` 時，說明框由點擊位置向固定安全框展開，共 10 tick；為 false 時立即顯示完整框。
3. 說明框開啟時，左鍵或右鍵框外可關閉；框內文字必須換行且裁在安全框內。
4. 所有標題與本文只存於 `assets/i18n/ui.json`，Go 程式只保存 key。

## 實作邊界

- `helpExpandRect` 是純幾何函式，輸入來源點、目的矩形、tick 與是否展開，輸出當幀矩形。
- tick 0..9 做線性插值，tick >=10 回傳完整目的矩形；停用設定直接回傳目的矩形。
- 本切片先閉合原版 SETTINGS 的正常玩家路徑；其他畫面日後可重用同一呈現器，但不得因 helper 存在就宣稱所有原版 help hotspot 已逐一映射。

## 驗證

- 純規則測試：立即顯示、起點、十步單調展開、終點。
- UI 測試：右鍵不切換選項、依目前暫存設定決定動畫、標題／本文 key 可解析。
- headless 畫廊抽樣確認 640×480 安全框與既有 SETTINGS 畫面未退化。
