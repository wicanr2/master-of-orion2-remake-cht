# 原版武器表與艦體表(執行檔一手資料)

與 [`special-device-table.md`](special-device-table.md) 同一趟挖出來的(第 79 項(武器表與艦體表))。

## 一、武器表:`0x17F807` 起,46 筆 × 28 (0x1C) 位元組

```
+0  dd     名稱字串指標
+4  dw     武器編號(0..45,連號)
+6  dw     解鎖科技編號(0 = 沒有,安塔蘭/太空怪物專用)
+8  db     類別:0 光束 / 1 飛彈 / 2 魚雷 / 3 炸彈 / 4 戰機艙 / 5 特殊武器
+9  db     彈藥數(255 = 無限)
+10 dw     佔格(手冊 p.124-125 的 Size 欄)
+12 dw     成本
+14 dw     旗標(未解讀;值有 4/16/32/128/256/1026/2048/4096 這種單一位元的樣子)
+16 dw     傷害下限
+18 dw     傷害上限
+20 2×db   第二組傷害(戰機艙這一欄是**艦載機自己的**傷害)
+22 dw     未解讀
```

定位方式:`Special_Devices_Available_`(`0x5F9EA`)在「這一格是武器」那條分支用
`imul eax, 1Ch` + `word_17F80D`,而 `0x17F80D − 0x17F807 = 6` —— 與特殊裝置表同一個版面家族。

### 這張表抓到 remake 一個抄錯

**質子魚雷的傷害與佔格是 A-M 魚雷那一格。** 手冊 p.125 的表在 PDF 抽取後欄位打散成:

```
A-M Torpedo / 20 / 30 / 25 / Proton Torpedo / 40 / Plasma Torpedo / 120
```

當初讀成「Proton/A-M Torpedo 25」,而執行檔逐格給出:A-M **20 格 25 傷**、
質子 **30 格 40 傷**、電漿 **40 格 120 傷** —— 手冊那幾個數字一個不差,只是欄位歸屬相反。
已訂正三處(`weapon_damage.go` / `shipspace.go` / `session.go` 的元件清單)。

### 這張表證實了一個版本差異

電漿砲:元件清單存 **20**(1.50),而執行檔給 **30** —— 因為反組譯的是 **1.31 的 exe**。
`RuleProfile.PlasmaCannonMaxDamage` 早就寫著 1.31 = 30,兩份獨立來源在這一格對上了。

### 兩件手冊沒講、這張表講了的事

1. **飛彈本體的 Size 是 0**。手冊與 IDA 均支持彈架的 10/20/30/35/40；艦艇設計已依
   2/5/10/15/20 發選擇，單值 10 只留給沒有逐艦 loadout 的衛星／轟炸代理消費端。
   那是**建模取捨**,既沒被證實也沒被推翻 —— 標記已改成這樣寫。
   ⚠ 不要「照執行檔訂正成 0」,那會讓飛彈完全不佔空間,比現在更失真。
2. **編號 40..45 沒有解鎖科技**,是安塔蘭/太空怪物專用武器,玩家造不出來。

### 成本欄為什麼沒接線

執行檔的武器成本(雷射 5、死光 75)是 remake 尺度(雷射 20、死光 350)的約 1/4,
而**艦體成本的方向相反**(remake 巡防艦 18、執行檔 70)。只換一邊會把相對平衡弄壞,
而艦體表的成本欄目前有一格對不上(見下),所以兩邊都先不動。

## 二、艦體表:`0x180020` 起,stride 36 (0x24)

```
+0  dw  空間      25 / 60 / 120 / 250 / 500 / 1200   ← 手冊 p.121 Space 欄,逐格相同
+2  dw  陸戰隊    5 / 8 / 12 / 20 / 30 / 50          ← 手冊 p.121 Marines 欄,逐格相同
+4  dw  ?         4 / 10 / 30 / 50 / 80 / 150
+6  dw  ?         4 / 10 / 30 / 50 / 80 / 150
+8..+24  多欄未解讀
+26,+30  兩個指標
+34 dw  ?         70 / 250 / 600 / 1500 / 4000 / **400**
```

前兩欄與手冊 p.121 **逐格相同**,所以記錄起點與 stride 是確定的。

⚠ **`+34` 那一欄不下結論。** 前五格(70/250/600/1500/4000)看起來像成本,而末日之星是 **400**
—— 比泰坦低一個數量級,不可能是成本。可能是欄位認錯、可能有特例、也可能那一欄根本不是成本。
**在解釋得通之前不寫進程式碼**,免得又多一條「當初就寫錯」的斷言。

順帶:這張表的記錄數超過 6 筆(第 7 筆空間 300、陸戰隊 20),推測是星基/戰鬥站/星辰要塞
那一族 —— `orbital_bombardment.go` 對它們的 space 預算標的是【近似】值,那個標記有機會升級,
但要先確認第 7 筆之後的排列。
