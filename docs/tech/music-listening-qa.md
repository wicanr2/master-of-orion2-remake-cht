# 音樂逐曲驗收紀錄

## 目前結論（2026-08-10）

Remake 的音樂與音效已接入 `internal/audio` 與 `cmd/moo2`：主選單、星系、外交、戰鬥
BGM，以及按鈕／戰鬥 SFX 都有播放入口。這份紀錄把「可由 Docker 重現的技術檢查」與
「必須真的聽到聲音的人耳驗收」分開，不把無音訊輸出的 headless 測試誤稱為聽感通過。

## Docker 技術抽樣

使用使用者自備、唯讀掛載的正版 MOO2 資料，透過 `cmd/moo2 -audiodump` 解出 WAV，並由
`internal/audio` 真檔測試檢查格式、長度、峰值與非靜音樣本。

| 資產 | 技術結果 | 用途 |
|---|---|---|
| `STREAM.LBX` | 8 首 WAV，全部可解碼且有非靜音樣本 | 一般場景／背景音樂 |
| `STREAMHD.LBX` | 20 首 WAV，全部可解碼且有非靜音樣本 | 高音質場景／主選單音樂 |
| `SOUND.LBX` | 68 個音效 WAV，含按鈕、命中、護盾、飛彈與爆炸音 | SFX |
| 合計 | 96 個 WAV，dump 與真檔測試退出碼 0 | 技術檢查完成 |

場景入口由 `audio-track-map.md` 與 `audiotrack.go` 的既有映射提供；戰鬥視覺特效
`CMBTSFX.LBX` 是影像動畫，不列入音效數量。

## 尚待外部驗收

- 在有喇叭／耳機的桌面逐曲播放 `STREAM`／`STREAMHD`，確認每首曲子的音色、循環尾端與
  場景情緒。
- 在主選單、星系、外交、戰鬥各走一次，確認 BGM 切換、SFX 音量與同時播放不爆音。
- 若要公開推廣影片，必須以有發布權的配樂替換目前使用正版資料抽出的原版音樂；三平台
  套件不含原版音樂與遊戲資料。

這項人耳驗收不阻塞 remake 的音訊接線，也不會被誤記為原版動態 oracle 已通過。
