# 載入／儲存遊戲彈窗外部文案與版面規格

## 文案契約

固定玩家文案全部來自 `assets/i18n/ui.json` 的 `loadsave.*` 鍵：

- 返回主選單／星圖的轉場名稱；
- 空槽、自動存檔空槽、無名帝國、編號槽、自動存檔與星曆格式；
- 空槽、不可覆寫自動存檔、未選槽、無對局、寫入失敗及讀取失敗訊息；
- `LOAD`／`SAVE`／`CANCEL` 按鈕標籤。

Go 只保存鍵、格式參數、typed `SaveSlotInfo` 與不可翻譯的日期格式契約。不得再使用
`tr(中文, English)`，也不得以字串串接產生可見標籤。

## 幾何與溢位政策

下列座標均為 640×480 邏輯座標，先加視窗原點 `(winX,winY)`：

- 每格可見／點擊框：`(22,22+31×i,232,27)`。
- 第一行名稱：`(32,24+31×i,170,25)`；單行從槽位上緣 +2px 繪製，安全框仍涵蓋至槽底，
  右界停在對局圖示前。
- 第二行星曆：`(32,36+31×i,88,13)`。
- 第二行時間：`(122,36+31×i,82,13)`；受限於原版圖示前 84px 欄寬，拉丁日期／時間使用
  7px 小字層級，右界與圖示保留 2px。
- 對局圖示錨點：`(206,34+31×i)`，不屬於文字安全框。
- 動作鈕與取消鈕文字框直接取各自可見／點擊矩形，內縮 `(4,2)`，文字中心必須與熱區中心一致。
- 狀態訊息框：`(8,winY+winH,624,min(32,480-(winY+winH)))`，置中單行；過長時明示截斷，
  不得畫出 640×480。

名稱、星曆與時間均採單行量測後截斷；任何欄位不得依賴 painter clipping。空槽只使用第一行框。

## 原版資產與 fallback

- 正版路徑使用 `GAME.LBX#20` 背景、`#21/#22` 按鈕、`#23/#24` 單人／熱座圖示，
  palette provider 為 `MAINMENU.LBX#21`。
- 英文模式保留按鈕圖上的烘字；繁中模式只擦除文字帶後疊 `ui.json` 標籤。
- 未指定外部向量字型時，英文動態槽位與訊息使用內建點陣字 fallback；不得以 nil 字型略過，
  否則高解析錄→放會 panic，原生解析度也無法畫動態欄位。
- 任一資產缺失時保留 typed 槽位、熱區、自繪按鈕與所有外部文案，不能因解碼失敗失去存讀檔功能。
