# Auto Select Colony 設定規格

## 行為

1. `GameSettings.AutoSelectColony` 為唯一設定來源，預設關閉並隨存檔往返。
2. 星圖點擊星系時，若設定開啟且該星系對應玩家殖民地，先更新 `SelectedStar`，再把 `sceneBuilder.colonyIdx` 設為該殖民地索引並進入單一殖民地畫面。
3. 設定關閉、星系不屬於玩家或索引無效時，沿用星系資訊面板流程。
4. F5／F6 是明確手動巡覽；成功找到下一個目標後，必須把 `AutoSelectColony` 關閉並保存於目前對局設定，再更新 `SelectedStar`。沒有巡覽目標時不得改動設定。
5. 此功能不新增玩家文案。既有轉場名稱必須使用 `assets/i18n/ui.json` 的穩定鍵，不可把中文或英文句子寫進 Go。

## 介面轉接邊界

原版在星系內項目堆疊選中玩家殖民地；remake 沒有這層 widget。直接進殖民地畫面保留「自動把玩家帶到可管理殖民地」的可見結果，標為介面轉接近似。

## 驗收

- 開啟＋我方殖民星：回傳正確殖民地索引。
- 關閉／非殖民星／nil session：不自動進入。
- F5／F6 成功巡覽：設定由開變關，其他設定不受影響。
- F5／F6 無目標：設定維持原值。
- `go test ./...` 與中文 headless 畫廊通過；抽看星圖、殖民地畫面與設定頁。
