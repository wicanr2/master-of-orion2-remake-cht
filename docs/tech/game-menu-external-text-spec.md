# 對局內遊戲選單外部文案與版面規格

## 文案契約

固定玩家文案全部由 `assets/i18n/ui.json` 的 `gamemenu.*` 鍵供應：

- 六顆按鈕：儲存、載入、新遊戲、離開、設定與返回；
- 音樂與音效標籤；
- 遷移連線格式、開／關狀態；
- 無存檔訊息與三個轉場名稱。

Go 只保留穩定鍵、typed 狀態、格式參數與不可翻譯的動作 ID。不得使用
`tr(中文, English)`、字串串接或直接字型繪製產生玩家文案。

## 文字安全框

座標均為 640×480 邏輯座標，視窗 fallback 尺寸為 `(144,25,276,376)`：

- 按鈕文字框直接使用各按鈕圖框，內縮 `(4,3)`；文字中心必須與可見圖框及點擊框相同。
- 音樂標籤框 `(203,153,170,31)`，音效標籤框 `(203,230,170,31)`。
- 遷移連線列使用 `settingsRowRect()` 完整圖框，內縮 `(4,2)`。
- 訊息列使用視窗底端到 480 之間最多 30px，不得把 baseline 直接畫到畫布外。

各框採單行量測與省略號截斷；按鈕、設定列與訊息都不依賴 painter clipping。

## 烘字與缺資產 fallback

- 英文且 `GAME.LBX#1..6` 可用時，保留圖上原版按鈕烘字。
- 音量標籤不論語言都擦除背景烘字帶後以 JSON 繪製；不依賴背景是否有完整 `Music`／`Sound Fx`。
- 繁中時擦除按鈕文字帶並疊上 JSON 譯文；英文按鈕資產缺失時，也以 JSON 英文繪製。
- 背景缺失時繪製自有外框，並顯示 JSON 音量標籤；不可留下全黑無邊界畫面。
- 音量條仍使用 `GAME.LBX#7`；缺失時保留可點擊的自繪框與 typed 音量狀態。
