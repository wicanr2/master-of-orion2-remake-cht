# 誠實現況評估(moo2 remake)

> 起於 2026-07-04 使用者實測回饋「還原度約 20%」。**該 20% 是接原版 LBX 美術前的快照,已被 2026-07-05~12 多輪超越,勿再當現況錨點。** 本文保留核心紀律 + 現況 + 誠實 caveat;逐輪「怎麼接的」細節見 git log 與 `WORKLIST.md`,不在此重複佔篇幅。

## 核心紀律(此文存在的理由,rulebook/65)

還原度**只以「對原版實測比對」驗收,不看單元測試綠 / 新增系統數**。曾多輪用「加自製系統 + 測試綠 + headless 有畫面」謊報進度,但那些係數多是自編近似值(程式碼自標「remake 調校值」),測試只證自製邏輯自洽、不證對齊原版——使用者一玩就見差異。**還原 = 對齊原版,不是長出新東西。誠實標注每個數字來源,自編的就說是自編的。**

## 現況(2026-07-12)

可玩的多帝國 4X 迴圈(headless 探針驗:玩家 + 3 AI 各自擴張、經濟健康、可經三條勝利路徑贏一局、無 panic):

- **① 音樂 ✅**:PCM 場景 BGM(menu/galaxy/diplo/combat)+ 按鈕/戰鬥音效;僅曲目↔場景精確身分待人耳定案。
- **② 忠實新遊戲流程 ✅**:版本選擇 1.3/1.5 → 難度/星系 → 14 族肖像選擇 → 自訂點數 → 命名旗色 → 真母星(人口職務模型農4/工1/科3,SAVE10 校準)。
- **④ gameplay 子系統全接**(非死碼):經濟(建築效果/重力/士氣/礦產/地形改造/污染/成長/收入/指揮點數)、科技抉擇樹、戰鬥(beam/飛彈/球狀分流 + 艦艇佔格 + 武器 mod)、地面戰(陸戰隊/戰車/軌道轟炸)、拓殖、多 AI(N=3,含 AI-vs-AI 關係矩陣)、間諜偷科技、領袖技能、三勝利路徑(征服/議會忠實搖擺票/安塔蘭反攻)。
- **經濟校準**(手冊考據 + SAVE10.GAM oracle + moo2sim 探針):每科研 3、開局 BC 50、人頭基礎收入 1 BC/人、稅率預設 15、指揮基礎供給 5。60 回合玩家 BC 健康爬升(55→419)。詳見 `docs/knowledge-base/original-gameplay-reference.md` §7、`docs/knowledge-base/manual-cht/`。

## 仍近似 / 待校準 / oracle-gated(誠實 caveat)

- **③ 按鍵逐畫面像素對齊**:openorion2 那條線已做到頂(2026-07-12 逐畫面比對 `initWidgets` 真值,把有真值卻用 PIL 的補齊:planets 補第8列、research/fleet/officer/info 座標校正;menu 本就 0px)。

## 中文化覆蓋率(2026-08-07 實測)

譯表 **5,046 條**(24 份 TSV),真正未翻 **1 條**——`BC`(貨幣縮寫,原版 UI 也是 BC,刻意保留)。
程式碼裡唯一寫死、會顯示到畫面上的英文在 `cmd/moo2/play.go`(已淘汰的 `-play` 簡約殼,
非主遊戲)。主選單的語言切換 2026-08-07 補上(先前只有啟動旗標 `-lang`)。

> ⚠ 這一節量的是**中文方向**(中文模式下還有沒有漏翻的英文),**不代表語言切換功能完整**。
> 反方向(英文模式下還有沒有露出來的中文)是另一回事,見下一節——**別把這兩個數字混為一談**。

量法——**只靠 `$1 !~ /^#/` 濾掉註解,不要另外加 `FNR>1` 跳表頭**:24 份裡有 23 份第一行是
`#` 註解(這條濾掉了),只有 `help.tsv` 第一行就是資料。多加一條跳首行會把那筆真資料吃掉,
數出來變 5,045。

```bash
# 譯表總條數
awk -F'\t' '$1 !~ /^#/ && $1 != ""' assets/i18n/*.tsv | wc -l
# 其中未翻的
awk -F'\t' '$1 !~ /^#/ && $1 != "" && ($2=="" || $2==$1)' assets/i18n/*.tsv | wc -l
```

## 英文模式覆蓋率(2026-08-07 首次實測,**未完成**)

CLAUDE.md 明列「允許在主選單選擇中文/英文」。中文方向做完了,英文方向沒有——
`-lang en` 跑起來,**多數 remake 自繪畫面仍然整片中文**。這不是取捨,是缺口。

### 為什麼會這樣(兩條路徑,只有一條天生雙語)

| 路徑 | 做法 | 英文模式 |
|---|---|---|
| **overlay**(`overlayScreen` / `runOverlay`) | 擦掉原版美術上烘死的英文,疊中文 | **自動正確**——整段擦字疊字被 `lang == Traditional` 擋掉,原版英文直接露出來 |
| **自繪**(remake 自己畫的面板) | `fnt.Draw*` 直接畫程式裡的字串 | **仍是中文**——底下沒有原版英文可露,字串本身寫死中文 |

overlay 那條路徑的英文其實不是「翻譯」,是原版點陣美術本體,所以字型/字距都是對的。
自繪畫面沒有這個福利。

### 現況數字

英文模式有兩種修法,**優先用第一種**:

- **讓路**——畫面底下是原版美術、英文烘在圖上時,英文模式整段跳過「擦底疊字」,
  露原版那張。畫面 100% 是 1996 年的點陣字,比用 Noto 重畫更像原版,而且一行 code。
- **`b.tr(zh, en)`**(`cmd/moo2/interactive.go`)——底下沒有原版英文可露時才用。

### 更底層的一層:引擎自己就講中文

`internal/` 有 **2,188 條**寫死中文,其中 1,501 條是星名池(829)+ 艦名池(672)——那兩份是
原版英文池的譯本,英文原文在原始資料裡,要回頭接得回來。剩下約 690 條是引擎產生的顯示字串
(`session.go` 228、`gamedata/buildings.go` 83、`colonization.go` 61、`gamedata/events.go` 44…)。

具體症狀:熱座交接畫面英文模式下寫 `Next: 第 2 位玩家(布拉西人)`——UI 那一層已經雙語了,
但 `SeatName()` 回傳的字串本身是引擎在 `internal/shell/hotseat.go` 組出來的中文。
**UI 層單獨修不掉這種**,得整層一起處理。

### 量法

```bash
# cmd/moo2 自繪畫面裡寫死的中文(排除測試與整行註解;含少量 log/錯誤訊息)
grep -rh --include='*.go' --exclude='*_test.go' -v '^[[:space:]]*//' cmd/moo2 \
  | grep -o '"[^"]*[一-鿿][^"]*"' | wc -l
```

⚠ **`tr(` 的數量不是覆蓋率**——「讓路」那條路徑一個 `tr()` 都不需要,`gamemenu.go` 就是
0 個 `tr()` 但英文模式完全正確。要看覆蓋率只能跑 `-lang en` 的過場截圖廊逐張看。

`cmd/moo2/lang_coverage_test.go` 擋的是另一件事:新增一族 / 一個旗色時漏填英文欄。
那種漏填不會編譯失敗、中文模式也完全正常,只有英文模式會出現空白或中文。

### 收尾原則(下一位接手用)

1. **有原版美術可露的,就露**,不要自己再畫一次英文——種族選擇畫面就是範例:英文模式整段
   跳過擦字疊字。畫面會更像原版,不是更省事而已。
2. **`tr()` 的英文取原版用語**(`START NEW GAME`、`CANCEL`、`SELECT RACE`),不要自譯。
3. 英文比中文長:`hotseat.go` 那句英文說明第一版就溢出 320px 面板右緣。**每加一段英文,
   要用 `-lang en` 跑一次過場截圖廊看實際排版**,不要只看編譯過。
4. 引擎層(`internal/`)是獨立的一輪,先別跟 UI 層混在一起做。
