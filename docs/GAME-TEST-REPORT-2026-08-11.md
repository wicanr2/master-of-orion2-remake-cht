# 遊戲測試報告（2026-08-11）

## 結論

本輪採抽樣測試，不宣稱全遊戲回歸完成。以正常玩家入口、畫廊輸出與既有規則測試證據評估，
目前 remake 可玩度為 **70／100（暫定）**：主選單、新局、種族／命名、星圖、艦隊、殖民地、
外交與戰術入口可達，未觀察到崩潰、panic 或卡死；但長回合經濟循環與數個高風險玩法尚未完成
玩家路徑驗證，因此不提高評分。

本報告由兩個測試代理分工產出：

- 測試員 A：正常玩家路徑與核心玩法抽樣。
- 測試員 B：UI／音訊／多人／三平台包裝對照；B 本輪在收束前沒有重新執行命令，以下明確區分
  既有證據與本輪新證據，不把舊產物冒充最新驗證。

### `LBX asset id 31` 回歸確認

測試員 A 收束報告引用的較早批次日誌曾出現：

```text
載入新遊戲設定: lbx: 資產 id 31 超出範圍(共 30 個)
```

這是舊批次證據，不能直接代表目前工作樹。主流程隨後以目前工作樹在 Docker + Xvfb 重跑 `-gamegallery`：
產出 35 張 PNG、退出碼 `0`，`資產 id 31 超出範圍` 出現次數為 `0`，`panic`／`fatal`／`error` 訊息數為 `0`。
因此本輪不再把 asset id 31 列為目前版本的已知警告；若未來更換資料版本，仍應保留版本／資產數量
fallback 的回歸測試。

## 測試員 B：UI／音訊／多人／包裝

B 的收束回報指出：本輪沒有重新執行新 Docker、建置、抓圖或分析命令，因此其新鮮度不足，不能用
來宣稱目前工作樹的多人或三平台包裝已通過。可引用的既有證據包括：舊畫廊 `rc=0`、26 項 UI 抽樣、
音訊抽取 `rc=0`（96 WAV：20 `STREAMHD`、8 `STREAM`、68 `SOUND`），但沒有本輪完整 `ffprobe`、
場景切換或人耳 A/B 驗收。

本輪另由主工作流程完成新版推廣片的 Docker 驗證：`72.000000` 秒、1280×720、30 fps、48 kHz
stereo，音訊 `mean_volume=-19.2 dB`、`max_volume=-2.1 dB`，並抽查標題、星圖、科技、外交、
戰術、地面戰、多人與 CTA 畫格。這是影片檔案驗證，不等同於逐曲人耳驗收。

公開三平台包也完成 Docker 結構抽樣：Linux AppImage 可解包且為 x86-64，Windows ZIP 只含
`moo2.exe`／`moo2sim.exe`／`assets/i18n`，macOS universal tar 的兩個 binaries 均由 `lipo`
確認含 `arm64`／`x86_64`；三者均未找到 `.LBX`、`.ttc` 或 `.sf2`。這仍不是 Windows／macOS
原生主機執行測試。

## 分級與發行判定

- **S0／S1：未觀察到**：已測基本導覽沒有崩潰、panic 或卡死。
- **S2：驗證阻塞**：20 回合穩定性、完整高風險玩法與原版動態 oracle 尚未形成新鮮玩家路徑證據。
- **S3：中度風險**：魚雷 NR 距離數值回歸不足，以及客製／間諜／領袖流程缺少完整操作證據。
- **S4：低度問題**：部分測試結果依賴既有產物，需在下一輪用當前 commit 重新生成可追溯證據。

目前可作為「可玩 alpha／release candidate 準備中」，不應寫成「完整遊戲測試通過」。公開 GitHub
Release 仍必須排除使用者私有原版資料、原版音樂與 CJK 私有字型；本機完整版和含 `STREAM.LBX`
音樂的 72 秒影片只作授權範圍內預覽。
