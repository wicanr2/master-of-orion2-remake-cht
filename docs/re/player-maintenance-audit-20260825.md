## 強推論與停止線

- `sub_E4F49 @ 0xE4F49` 對每位存活玩家先呼叫 `sub_EE0B0`，之後才在
  `0xE4F8E..0xE4F95` 把本回合淨收入 `player+0xB2` 加進國庫 `player+0x32`。因此危機處理
  的判定量是「目前國庫 + 已算出的本回合淨收入」，不是只看其中一欄。
- `sub_EDB35 @ 0xEDB35` 是建築出售迴圈：掃描所屬殖民地的建築旗標，依
  `sub_ED9EC @ 0xED9EC` 的價值挑最低候選，呼叫 `sub_145EA` 移除建築，並把原始建造成本
  `off_17EB3D[id].cost / 2` 加回國庫。相同最低分使用 `sub_1247A0` 做 reservoir tie-break。
- 建築共有三輪篩選，呼叫順序固定：
  1. `sub_EDAE2 @ 0xEDAE2`：成本大於 0、raw category 不是 1／3、ID 不是 9。
  2. `sub_EDB1D @ 0xEDB1D`：成本大於 0。
  3. `0xEDB2D` 的三條原始指令 `cmp ax,9; setnz al; retn`：ID 不是 9。
- `sub_ED9EC` 的基本價值是建造成本；ID 7／15 乘 8，12／20／31 乘 7，21 乘 6，
  25 乘 4。ID 2／22 在政府 raw 值 0..3 時通常乘 8；ID 22 若同殖民地有 ID 2 則不乘。
  ID 23 有另一個同殖民地旗標例外。這些倍率影響「先賣哪棟」，不影響退款額。
- `sub_EDCBF @ 0xEDCBF` 在仍有赤字時依玩家槽順序裁撤間諜，最多裁到補足赤字；
  `sub_EDFE0 @ 0xEDFE0` 最後逐一解雇 `sub_94A9D` 回傳正維護費的領袖。
- `sub_EDDF7 @ 0xEDDF7` 掃描 `dword_197F9C`、stride `0x81` 的艦艇表；`+0x63` 是 owner、
  `+0x64` 是 status、`+0x11` 是 `ShipDesign.Type`、`+0x5E` 是設計成本、`+0x7F` 是 mission。
  先前把這條鏈稱為「放棄殖民地」是錯誤斷言；`+0x64=7` 是把艦艇標為已拆除。
- 候選條件與呼叫矩陣已證實：owner 相符、status `<3`、指定 type；兩個旗標分別要求
  `sub_EDD73` 的友軍支援星條件，以及 mission 屬於 `{0,3,7}`。type 依序涵蓋 4 前哨船、
  2 運輸艦、0 戰鬥艦與 1 殖民船；三段拆船呼叫與三輪建築出售交錯，最後才裁間諜、
  補做戰鬥艦、解雇領袖與第三輪建築。
- `sub_EDD73 @ 0xEDD73` 對停泊或抵達星系的艦艇檢查該星 `+0x38` 的玩家位元。強推論為
  「位於己方殖民地／前哨支援星」；成立時退款為帶號設計成本 `/4`，否則仍可拆船但退款 0。
- `sub_EE0B0 @ 0xEE238..0xEE273` 只替 type 0 戰鬥艦建立 `dword_1AA3F0` 候選矩陣：
  對每個存活對手呼叫 `sub_5EF17 @ 0x5EF17` 累加逐艦戰鬥效能。`sub_EDDF7` 由最高艦艇索引
  往低處掃描，選嚴格最低分；同分保留先遇到的最高索引。remake 尚無同一套逐對手評估器，
  因此只有戰鬥艦的「最弱者優先」分數採可玩近似。
- `sub_ED908 @ 0xED908` 的四個 raw ID 已由 `locret_ED903` bytes `C3 06 1E 13 23` 閉合為
  35 研究實驗室、19 銀河網路中心、30 行星超級電腦、6 自動實驗室，依 35／19／30／6
  順序移除並退表列成本一半。唯一寫入 `player+0x59D` 的 `sub_DC288 @ 0xDC288` 位於 AI
  科技選擇鏈，當映射研究結果達 75 以上時設 1；強推論為 AI 晚期／超科技研究設施清理旗標，
  不是玩家可設定的四槽狀態。
- 納貢的跨帝國轉帳現已在 shell 另行處理；本輪不重複併入 engine，以免同一筆成本扣兩次。

## 證據等級與本輪實作邊界

- 已證實：危機觸發時點、完整拆船呼叫順序與欄位、四分之一／零退款、三輪建築篩選、
  最低價值候選、半價退款、間諜裁撤與領袖解雇。
- 強推論：相同最低價值的 tie-break 在 remake 使用穩定順序；原版使用全域 RNG，尚未追回
  此呼叫點的種子狀態。
- remake 近似：`sub_5EF17` 的逐對手戰鬥效能已定位到完整艦艇裝備／科技評估鏈，但 remake
  目前以自身戰力模型挑最弱戰鬥艦；這不影響 type 1／2／4 支援艦，原版也未替它們填矩陣。
- 非玩家阻塞：`player+0x59D` 是 AI 科技選擇端寫入的晚期旗標；只有補齊原版 AI 經濟鏈時，
  才需把四棟研究設施的預先清理接到 AI，而不應再列作玩家破產缺口。
