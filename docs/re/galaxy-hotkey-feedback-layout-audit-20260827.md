# 星圖快捷鍵回饋文案與版面稽核（2026-08-27）

- 原版輸入：`Orion2.exe`，SHA-256
  `7ae2ac2e5904ca330009af2827279d889906b0b9b7a8854c38eb707a56e955b5`。
- IDA 資料庫：`Orion2.exe.i64`，SHA-256
  `4a01791fcf877ed87a740a54748694ab34a02675e3117dac052aeaa3f883944e`。
- 工具：IDA Pro 9.4／IDAPython，映像 `ida-pro-9.4-idapython:py312-v1`；位址均為

- 非破壞性匯出器：`tools/ida/audit_galaxy_hotkeys_ui.py`；輸出：

  caller 與資料參照，不修改 `.i64`。

## 已證實

1. 官方手冊的星圖快捷鍵章節規定 F9 為兩階段測距：先點第一顆星，再把游標移到其他星，
   顯示兩星之間的秒差距；F10 使用上次存檔名稱直接覆寫。
2. `sub_825A8 @ 0x825A8..0x82809` 是星圖輸入分派候選，唯一直接 caller 是
   `sub_86188 @ 0x86188`。`0x825B9..0x825F2` 對負值輸入碼做範圍判斷及十項 jump table，
   與既有快捷鍵工程日誌的分派定位一致。
3. `sub_EBE79 @ 0xEBE79..0xEBEB7` 由四個函式呼叫；它計算兩點平方距離，以 `0x384=900`
   除法及整數平方根後向上取整。`900=30²`，與一秒差距 30 raw units 的既有證據一致。

## 強推論、remake 適配與未知

- **強推論：**F9 顯示值應與戰略航程共用同一秒差距規則，不應在 UI 另算一份距離。
- **remake 適配：**原版 F10 是無確認覆寫；現行短暫成功／失敗訊息是必要的現代回饋，
  不是已證實的原版逐字文案。作業系統錯誤內容是 runtime 值，固定前綴仍須由 catalog 提供。
- **未知：**F9 提示與結果的原版逐字內容、字級、面板幾何、F9 再按一次取消的原版行為，
  以及 F10 是否有原版短暫成功訊息。不得把現行游標旁提示升格為原版 parity。

## 現行缺陷

- `hotkeys.go` 仍以 `tr(中文,英文)` 保存三則快速存檔回饋、兩則測距提示與距離格式。
- 測距提示直接畫在 `(mx+12,my-6)`，游標靠近右／上／下邊時可越出星圖或邏輯畫布；
  距離文字亦只有中心點，沒有可檢查的雙軸安全框。
- 快速存檔底板依未截斷字寬動態擴張，過長 OS 錯誤可壓入左側星球資訊面板或越出星圖。

## Remake 對映與驗收

- 六個固定模板移至 `assets/i18n/ui.json`；Go 只傳距離整數或 runtime 錯誤字串。
- 游標提示框在星圖 viewport 內翻邊／夾限；距離框以線段中點建立並夾限；快速存檔使用
  星圖右下固定訊息框。三者皆經 `textSafeRect` 先截斷再繪製，底板與文字共用同一矩形。
- 來源契約、雙語最長字串、四角游標、距離中點與快速存檔錯誤均須通過 containment；
  `28_measure.png` 實圖只驗證 remake adapter 版面，不代表原版逐像素一致。
