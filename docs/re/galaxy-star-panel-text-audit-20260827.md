# 星圖選星側欄文案與幾何稽核

## 證據來源

- 殖民條件與起始人口：官方手冊 p.55、p.61–62，整理於 `docs/tech/colonization.md`。
- 戰略轟炸玩家可見結果鏈：raw `sub_4257E @ 0x4257E` 與 caller
  `sub_4267B @ 0x4267B`，見 `docs/re/strategic-bombardment-audit-20260824.md`。
- 艦隊航行模型：`docs/re/parity-matrix.tsv` 的「艦隊星際移動」列明原版
  `Move_All_Ships_Toward_Stars_ @ 0xFFEEA`；remake 目前只有 ETA，明標可玩近似。

## 已證實與轉接邊界

- 固態未殖民行星可由殖民船建立殖民地，起始人口一單位；氣態巨星／小行星帶可建前哨站。
- 轟炸、入侵、心靈控制與陸戰隊載運的規則消費端已存在，但本頁不重新宣稱各公式精確度。
- 現行左下 `starPanel`、把多種行動壓成 190px 單行按鈕，以及把艦隊 ETA、環境與陸戰隊
  放在同一框，是**remake 可操作轉接**；沒有原版逐字或逐像素證據。

## 本輪發現

- 固定中英文標籤仍由 `interactive.go` 的 `tr()` 提供，違反外部文案契約。
- 面板 y=`326`、h=`132` 的底緣是 `458`，但心靈控制按鈕與文字框是 y=`446..466`；
  因此最下列有 8px 跑出可見框。這是可由座標直接證實的 remake 幾何缺陷，不是原版差異。
- shell 回傳的轟炸／入侵／拓殖失敗 `Reason` 仍是另一個規則結果文案切片；本輪只外置
  星圖側欄固定標籤與本地成功訊息，不把未改的動態 reason 隱藏成已完成。
