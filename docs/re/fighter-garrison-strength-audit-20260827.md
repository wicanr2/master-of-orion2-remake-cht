- 工具：IDA Pro 9.4／IDAPython；位址均為 IDA 線性位址

- 非破壞性匯出：`docs/re/evidence/fighter-garrison-ida-20260827.json`

## 已證實

1. `sub_5F64C` 不是「10／6／4 中隊乘上泛用戰機火力」。正常戰略模式的公式為：

   `min(64000, (max(beamMax-armor, 0)*beamWeight + max(bombMax-armor, 0)*bombWeight) / 2)`

2. 科技分支與權重如下；位址為 `0x5F69E..0x5F731`：

   | 最高戰機 | beamWeight | bombWeight |
   |---|---:|---:|
   | 攔截機 | 40 | 0 |
   | 轟炸機 | 40 | 24 |
   | 重戰機 | 32 | 24 |

   `player+0x136 == 3` 選轟炸機分支，`player+0x16A == 3` 優先選重戰機分支。

3. `sub_5699C @ 0x5699C` 從已知、類別 0、raw flags `& 0x0004` 的武器挑最大傷害。
   武器表實際符合者為 ID `1,3,4,5,9`；玩家正常可用集合不含怪物武器 ID 41。
4. `sub_56CA2 @ 0x56CA2` 從已知、類別 3 的武器挑最大傷害；預設 ID 21（核彈）。
5. `sub_5F871 @ 0x5F871` 取得最佳裝甲的單次減傷。`word_17F6C1 + 59*index`
   六階 raw word 為 `0,1,3,5,7,10`。
6. 直接呼叫端 `sub_5F747 @ 0x5F747` 在殖民地防禦強度總和中，僅於 colony record
   `+0x165` 非零時加入本函式結果，最後同樣夾至 64000。
7. `byte_199CB4 == 1` 時函式固定回傳 120；其模式語意尚未由本切片證實，因此只保留為
   原始模式分支，不把它命名成特定玩家玩法。

## 勘誤

`docs/re/01-gap-report.md` 舊段落曾以「只看科技、10／6／4 隊」判斷 remake 與原版一致。
這只證實原版沒有逐殖民地中隊庫存，沒有證實戰力公式。上述 bytes 與資料流已足以否定
「現行泛用戰機貢獻公式一致」的結論；歷史成因保留於 Git，本文件與 parity matrix 為現況。

## 強推論與未知

- `beamWeight`／`bombWeight` 是依資料流命名的工程語意；權重數值與運算已證實，名稱為強推論。
- `byte_199CB4` 的完整模式名稱未知。remake 正常玩家路徑不使用此固定 120 分支。
- 本切片證實的是殖民地防禦「戰略強度」；原版如何將總強度轉成逐架戰術單位仍是另一條證據鏈。
