# 是／否確認框玩家文案與版面稽核

## 輸入與方法

- 輸入：`Orion2.exe`，SHA-256 `7ae2ac2e5904ca330009af2827279d889906b0b9b7a8854c38eb707a56e955b5`。
- 資料庫：`Orion2.exe.i64`，SHA-256 `4a01791fcf877ed87a740a54748694ab34a02675e3117dac052aeaa3f883944e`。
- 工具：IDA Pro 9.4／IDAPython；位址為 IDA linear、DOS/4GW 映像。
- 可重生匯出：`tools/ida/audit_confirm_box_ui.py`。腳本唯讀分析 `/tmp` 資料庫副本，保留
  原始函式名、位址、指令及 bytes，不覆寫 `.i64` 名稱或註解。

## 已證實

`sub_77658 @ 0x77658..0x77860` 是共用確認框外層；IDA 顯示 34 個直接呼叫位置，故不是
單一遷移功能專用畫面。關鍵指令如下：

- `0x776D8..0x776F3` 建立快捷鍵 `"Y"` 的熱區：`(0xEB,0x12E)..(0x11E,0x143)`；
- `0x776F8..0x77719` 建立快捷鍵 `"N"` 的熱區：`(0x159,0x12E)..(0x18C,0x143)`；
- `0x77746..0x7775D` 把 `CONFIRM.LBX#0` 畫在 `(0xA1,0x75)`；
- `0x777AC..0x777C4` 以寬 `0xE0` 量文字高度，從字級 4 逐級降到 1，直到高度
  `<=0x7E`；
- `0x777C6..0x777DA` 呼叫 `sub_77A74(0xCC,0xD0,0xE0,文字)`，即左緣 204、
  垂直中心 208、欄寬 224。

`sub_778E4 @ 0x778E4..0x77961` 每幀先把兩個按鈕物件設為 frame 0，再依游標所在 widget
把其中一個設為 frame 1，最後分別在 `(235,302)`、`(345,302)` 畫出按鈕。Y／N 字串只用於
widget 快捷鍵；玩家看見的英文 YES／NO 烘在 `CONFIRM.LBX#1/#2`。

`sub_77A74 @ 0x77A74..0x77AD7` 再呼叫 `sub_103CAF` 量文字高度，並以量得高度的一半
調整 y，證實正文是垂直置中，而非從固定上緣開始排列。

## Remake 對應與證據等級

- **已證實**：底框、兩顆按鈕、熱區、正文欄寬／中心、hover frame 與原版縮字停止條件。
- **remake 近似**：現行字型沒有原版四級字體，故固定 12px、16px 行距，超出 126px 高度時
  在最後一行顯示省略號；不得把這項稱為原版精確文字排版。
- **外部文案**：繁中「是／否」及缺資產時的英文後備文字是 localization adapter，放在
  `assets/i18n/ui.json`；有正版資產的英文模式應保留原版烘字。
