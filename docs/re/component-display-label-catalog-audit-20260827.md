# 元件顯示名稱目錄稽核（2026-08-27）

## 範圍與證據

- **已證實（remake source）**：`shell.Component.Name` 同時被元件比對、存檔與特殊裝置查表使用；它目前是規則層的穩定鍵，不能為了翻譯直接改值。
- **已證實（原版資料）**：有 `UnlockTech` 的元件可由 `gamedata.TechnologyNames` 取得原版英文科技名；該表來自原版執行檔科技名稱表，既有來源與對應見 `docs/tech/component-tech-mapping.md`。
- **已證實（remake source）**：現行清單只有六個 `UnlockTech == TECH_NONE` 的顯示特例：`無武裝`、`無裝甲`、`無護盾`、`無`、`戰鬥電腦`、`重生程序`。舊註解所稱「五筆」與實際清單不符。
- **已證實（remake source）**：未知的無科技元件在英文模式會退回中文規則鍵，造成語言洩漏。
- **強推論**：戰鬥電腦是原版電腦研究鏈的抽象，重生程序則近似原版種族再生能力；這兩項不是原版單一科技名稱，故只把 remake 的顯示名稱外部化，不升格為原版精確元件。

## 結論

六個無科技特例與未知 fallback 必須由 `assets/i18n/ui.json` 的語意鍵提供。Go 端只保留「內部規則鍵 → 語意鍵」路由；有科技的英文名稱繼續讀原版科技表，繁中名稱暫仍讀既有 typed 元件資料。後者是尚待逐資料表外部化的既有邊界，不在本切片搬動規則鍵或存檔格式。
