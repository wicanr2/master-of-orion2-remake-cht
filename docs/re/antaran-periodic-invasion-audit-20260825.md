# 安塔蘭週期入侵靜態稽核（2026-08-25）

## 證據契約

- 輸入：`Orion2.exe` 1.31，SHA-256
  `7ae2ac2e5904ca330009af2827279d889906b0b9b7a8854c38eb707a56e955b5`
- 工具：IDA Pro 9.4；IDA linear，DOS/4GW LE object #1
- 唯讀匯出器：`tools/ida/audit_antaran_invasion.py`
- 原始函式名、位址、bytes 與運算元均保留；本文件語意名稱不取代原始定位。

## 已證實：回合入口與設定

1. `Next_Turn_Calc_ @ 0x136B3` 只在 `byte_199CAF != 0` 且
   `byte_1991B0 == 0` 時呼叫 `sub_63D92 @ 0x63D92`。前者是 Antaran Attacks
   開關（強推論，另由設定載入交叉參照支持），後者是安塔蘭已被擊敗閘門。
2. 星曆 `dword_192FD8` 由 `0x88B8`（3500.0）開始，每回合在 `0x13802` 加一。
3. `sub_63E4C @ 0x63E4C` 依 `byte_199CB5` 回傳 200／100／0。`0x13B0F`
   同一欄位的開局艦型初始化 consumer 證實它是科技等級 0／1／2，不是安塔蘭開關。

## 已證實：資源與建艦

1. `sub_645EC @ 0x645EC` 計算
   `elapsed = stardate - 0x88B8 - techDelay`；只有 `elapsed > 0` 且可被 25 整除時累積資源。
2. `period = elapsed/25`。難度 0..2 使用 100%，難度 3 使用 150%，難度 4 使用
   200%；每次加入 `ceil(period×scale/100)`。
3. 每個 pulse 必定把一份加入 offensive resource；若 defensive ship 尚未達上限，
   第二份加入 defensive，否則也加入 offensive。
4. 原始五個非零艦級成本表 `byte_181734` 是 `{2,5,12,30,75}`；offensive 上限
   `byte_18173D` 是 `{4,4,3,2,2}`，defensive 上限 `byte_181746` 是
   `{0,0,3,2,7}`。兩表實際配置九格，後四格為 0。
5. `sub_63FF0 @ 0x63FF0` 以資源、成本、現有數量與上限逐艘建造。難度 3／4
   分別把早期尺寸時間門檻縮為 150%／200% 速度；難度大於 2 第一次建成第 5 級艦時，
   九格成本表乘 90%（整數除法）。

## 已證實：出兵閘門與目標

1. `sub_63EDD @ 0x63EDD` 要求 offensive 艦艇加權值的四倍至少等於 defensive、
   offensive、兩個資源池的合計，且至少有一艘 offensive 艦尚未部署。
2. 每個符合條件的回合把 `word_199174` 加一，再擲 `Random(200)-1`；結果小於
   `word_199174+1` 才出兵。成功後 root 把累積器清零，並在部署成功時把本回合星曆寫入
   `dword_1991B1`。
3. `sub_22F5C @ 0x22F5C` 在所有存活帝國間建立人口／難度權重；Lucky 候選權重除以三，
   最後走平方權重抽樣。它不是固定攻擊玩家母星。
4. `sub_7826A @ 0x7826A` 檢查星系五個殖民槽，候選星只需至少一個 active colony
   屬於目標帝國。`sub_64311`／`sub_645A4` 最終在其殖民星中作均勻選擇。
5. `sub_6478D @ 0x6478D` 從尚未部署的 offensive 艦中挑可用艦級；`sub_643A0`
   一次最多部署五艘，建立 owner 8 的艦隊並寫入一般星際移動 route。

## 強推論與未知

- `byte_199CAF` 是 Antaran Attacks、`byte_1991B0` 是安塔蘭敗亡狀態：兩者的
  `Next_Turn_Calc_` 閘門語意與其他設定／勝利交叉參照一致，但本輪未重命名 IDA 符號。
- 出征艦隊抵達後沿用一般 `Search_For_Battles_`、快速／戰術戰鬥與殖民地結果鏈；本輪已證實
  它不是直接扣 BC／人口，但尚未把 owner 8 的所有 battle record 欄位逐欄閉合。
- 原版保存中途座標；remake 只有整段 ETA。此資料模型差異必須明示，不得冒稱逐座標 parity。
- 1.50 二進位未取得；以上只宣稱 1.31。
